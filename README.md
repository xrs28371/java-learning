# java-learning

Java 备考练习代码（南京航空航天大学金城学院《Java程序设计》，考试 2026-11-11），按老师课件章节整理。

## 结构

- `已整理/第1章-Java概述/`：Hello World、程序入口（Demo01、Main）
- `已整理/第2章-语言基础/变量与运算符/`：Demo02–Demo12（常量、变量与类型转换、运算符、三元）
- `已整理/第2章-语言基础/分支与输入/`：Demo13–Demo20（Scanner、if、switch）
- `已整理/第2章-语言基础/循环/`：Demo21–Demo26（for、while、do-while、break/continue、循环嵌套）
- 后续章节（第3章类和对象、第4章继承与接口、第5章数组与字符串、第6章异常）随学习进度新增同名文件夹。

每个小节文件夹里的 `总结/` 子文件夹放每个 .java 的同名内容总结（练了什么、关键结论、笔试易错点）。

代码由笔记本自动同步归档（文件名 DemoXX 为随手命名，内容以代码本身和总结为准）。
