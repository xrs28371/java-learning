# Cat6.java 总结

- 内容：`public class Cat6 extends Animal6`，继承抽象类 Animal6。重写抽象方法 `eat()`，输出 "eat fish"；两个构造方法：无参 `public Cat6() {}` 和带参 `public Cat6(String name, int age)`，带参构造里用 `super(name, age);` 把数据交给父类构造初始化。
- 知识点：子类构造调用父类构造。① 子类对象创建时一定先调父类构造：无参构造默认调父类无参构造，带参构造用 `super(name, age)` 显式调父类全参构造；② `super(...)` 必须是构造方法里的第一行语句；③ 重写抽象方法 `eat()` 是继承抽象类的硬性要求，不写就编译不过。配合 AnimalDemo6 的两种创建方式（无参 + set、带参一次到位），这个类演示了子类初始化父类数据的两种路子。
- 易错点：笔试高频点——`super(name, age)` 只能出现在构造方法第一行，写在第二行或普通方法里都是编译错误；子类构造不写 `super(...)` 时编译器自动补 `super()`，所以父类必须有无参构造（Animal6 有，Cat6 的无参构造才能正常工作）；如果父类只有带参构造、子类又不写 `super(...)`，编译直接报错。
