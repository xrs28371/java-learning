# JumppingDemo2.java 总结

- 内容（2026-11-08 更新后）：接口 `Jumpping1` 的测试类（旧版只是空类壳，现已补全）。main 方法里两处调用：一是 `Jumpping1 jj = new Cat3(); j.method(jj);`——接口引用指向实现类对象再传给操作类；二是直接 `j.method(new Jumpping1() { ... });`——用匿名内部类当场实现接口，重写 `jump()` 输出"猫可以跳高了"，不新建文件。
- 知识点：接口作为方法参数的两种传法——有名实现类对象 vs 匿名内部类；匿名内部类 `new 接口名() { ... }` 当场写出实现，常用于"只用一次"的场景；接口引用指向实现类对象是多态，`j.method(jj)` 里实际执行的是 `Cat3` 的 `jump()`。
- 易错点：匿名内部类后面必须跟 `);` 闭合（`new Jumpping1() { ... }` 后面的 `)` 是 `method(` 的右括号，别漏）；匿名内部类里重写方法要加 `@Override`，方法签名必须和接口一致；接口名 `Jumpping` 拼写有误（正确是 Jumping，多打了一个 p），引用时要照抄这个错拼；`Jumpping1 jj = new Cat3();` 里等号左边是接口、右边是实现类，写反了编译不过。
