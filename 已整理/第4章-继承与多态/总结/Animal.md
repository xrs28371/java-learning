# Animal.java 总结

- 内容：抽象类版本的 Animal（本轮改写，原先是带 `age = 40` 和普通 `eat()` 的具体类，现已改为抽象类）。类声明 `public abstract class Animal`，只含一个抽象方法 `public abstract void eat();`，没有成员变量、没有方法体。
- 知识点：抽象类不能实例化，只能被继承；抽象方法没有方法体，子类必须重写（否则子类也得是抽象类）。这是第 4 章「抽象类＋多态」组合练法的起点：父类只定规矩（吃什么这个行为必须有），具体吃什么由子类决定。
- 易错点：笔试常问「抽象类能不能 new」——不能，`new Animal()` 直接编译报错；抽象方法不能是 private、static、final（与重写要求冲突）；抽象类里可以没有抽象方法，但有抽象方法的类一定是抽象类。本文件是「抽象类＋接口 Cat」编程原型的父类部分，对照 Cat1.java、AnimalDemo.java 一起看。
