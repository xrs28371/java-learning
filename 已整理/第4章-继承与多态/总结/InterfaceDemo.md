# InterfaceDemo.java 总结

- 内容：接口 `Inter` 的测试类：用接口多态 `Inter i = new Interlmpl();` 创建对象，打印 `i.num`（10）、`i.num2`（20）和 `Inter.num`（10）；两行赋值 `i.num = 20;`、`i.num2 = 40;` 被注释掉并附注“不是常量为什么？接口中都是常量、默认被 final 修饰”；文件末尾的大段注释系统总结了接口的成员特点（成员变量只能是常量、默认 `public static final`；没有构造方法；成员方法只能是抽象方法、默认 `public abstract`）。
- 知识点：接口多态的写法是“接口名 变量名 = new 实现类()”，编译看左边、运行看右边；接口常量既可以通过对象引用（`i.num`）访问，更规范的是通过接口名直接访问（`Inter.num`）；接口中所有成员变量默认都是 `public static final` 常量。
- 易错点：注释里那句“不是常量为什么？”是学习时的疑问句，答案就写在下一行——接口里的变量默认就是常量，所以 `i.num = 20` 编译不通过；`i.num` 能编译通过只是因为常量也能通过对象引用访问，不代表它是普通成员变量，规范写法是 `Inter.num`；注释里“一个类如果没有父类，默认继承自 Object 类”这句放在接口成员特点里是串了内容——Object 继承说的是类，不是接口，复习时别把两处混在一起。
