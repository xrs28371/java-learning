# AnimalDemo6.java 总结

- 内容：Animal6（抽象类）的测试类，演示子类对象的两种创建方式。① 无参创建：`Animal6 a = new Cat6();`，再用 `setName("xra")`、`setAge(18)` 设值，打印 `a.getName() + a.getAge()`（输出 "xra18"），调 `a.eat();`（输出 "eat fish"）。② 带参创建：`a = new Cat6("xra", 10000);`，再打印 `a.getName() + a.getAge()`（输出 "xra10000"）。
- 知识点：抽象类子类的两种初始化路子。① 无参构造 + set 方法：先创建空对象再逐个赋值；② 全参构造 + super：创建时一次性把数据传给父类构造。两种方式结果一样，选哪种看场景。③ 多态引用 `Animal6 a` 既能调父类的 get/set，也能调子类重写的 `eat()`，运行时走子类版本。④ `System.out.println(a.getName() + a.getAge())` 里字符串和 int 用 `+` 拼接，直接连在一起，没有分隔符。
- 易错点：输出细节——`getName() + getAge()` 是字符串拼接，输出 "xra18"、"xra10000"，中间没有空格，笔试看输出题别自己脑补空格；`10000` 岁的年龄只是测试数据，程序上合法、语义上离谱，别当真；`a = new Cat6("xra", 10000);` 是给同一个父类引用换了新对象，旧对象不再被引用；父类引用调不到子类特有方法（Cat6 没有特有方法，这里没暴露）。
