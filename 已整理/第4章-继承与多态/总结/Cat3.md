# Cat3.java 总结

- 内容：`Animal3` 的子类。无参构造和带参构造 `Cat3(String name, int age)`，带参构造里调 `super(name, age)` 把名字和年龄传给父类构造；重写 `eat()` 方法，输出"猫吃鱼"。
- 知识点：继承 + 子类构造方法 + 方法重写。子类构造方法的第一行默认是 `super()`（调父类无参构造），这里显式写 `super(name, age)` 改为调用父类的带参构造；`@Override` 标注表示重写父类方法，运行时按实际对象类型决定调哪个版本（多态/动态绑定）。
- 易错点：代码注释里写"`super()` 就是调用父类的无参构造器"——这句话本身没错，但本行代码实际是 `super(name, age)`，调用的是父类的**带参**构造，不是无参构造，别把两者记混；笔试时 `super(...)` 有参无参要和父类实际有的构造方法对上号，父类没有对应构造会编译报错。`@Override` 拼写和位置（方法上一行）别写错。
