# CatDemo.java 总结

- 内容：测试类，`main` 方法里先 `new CatOperater()` 得到操作类对象 `a`，再 `new Cat()` 得到猫对象 `c`，调用 `a.useCat(c)` 把猫对象作为实参传进去；随后新增一段：`Cat e = new Cat(); e = a.getCat();`——用 `getCat()` 的返回值（一个 Cat 对象）给 `e` 重新赋值。末尾注释点明两个结论：「方法的形参是类名，其实需要的是该类的对象」「方法的返回值是类名，其实返回的是该类的对象」。
- 知识点：「类作为形式参数」+「类作为返回值」的完整调用链——创建被操作类对象（Cat）→ 创建操作类对象（CatOperater）→ 把被操作对象当实参传给操作类的方法（useCat）；以及接收返回值：`e = a.getCat()`，等号左边是 `Cat` 类型变量，右边是方法返回的 Cat 对象引用。实参和返回值传的都是对象的引用，方法内部拿到的是同一个对象。
- 易错点：别把传对象的 `a.useCat(c)` 和传基本类型的值混为一谈——传对象传的是引用，方法里对对象成员的改动会影响原对象；`new CatOperater()` 这一层容易漏写（没有操作类对象就调不了 `useCat`）；`e = a.getCat();` 前面 `Cat e = new Cat();` 是先创建再覆盖，笔试里常考这种“先 new 再被返回值替换”的写法——注意 `e` 最终指向的是 `getCat()` 里 new 出来的那个对象；`main` 方法签名 `public static void main(String[] args)` 一个字母都不能错。
