# Cat.java 总结

- 内容：`Cat extends Animal`，用 `@Override` 重写 `eat()`，输出「猫吃鱼」；新增成员变量 `age = 20`（与父类同名，构成变量隐藏）、`weight = 10`（子类独有），以及子类独有方法 `palyGame()`（输出「猫捉迷藏」）。
- 知识点：方法重写的三要素——方法名相同、参数列表相同、返回类型相同（或协变）；`@Override` 是编译期校验注解，写错签名会直接报错，建议永远带上。**变量隐藏**：子类同名变量 `age` 只是把父类的遮住，不是重写；父类引用 `Animal a = new Cat(); a.age` 仍得 40（见 AnimalDemo.java）。
- 易错点：重写时子类方法的访问权限不能比父类更严（父类 public，子类必须 public）；重写 ≠ 重载（重载是同名不同参、不涉及继承）。**拼写错误**：`palyGame` 应为 `playGame`（play 错写成 paly），方法名一旦定错，全文件引用都得跟着错，笔试手写时别顺手写错；父类引用调不到它，必须向下转型后才能调。
