# JumppingDemo.java 总结

- 内容：接口的测试类。`Jumpping j = new Cat7();` 用接口类型引用指向实现类对象，调 `j.jump();`，输出 "Cat7 jump"。
- 知识点：接口多态。① 接口类型引用可以指向任何实现了该接口的类的对象，`Jumpping j = new Cat7();` 就是标准写法；② 编译看左边（接口里有没有 `jump()`）、运行看右边（执行 Cat7 重写的版本），和抽象类多态是同一套规则；③ 换一个实现类（比如将来有个 Dog4 implements Jumpping）只需改 `new` 后面的类名，`j.jump();` 这行代码不用动，这就是“面向接口编程”的好处。
- 易错点：接口本身不能 `new`，`new Jumpping()` 是错的，只能 new 实现类；接口引用 `j` 只能调接口里声明的方法，实现类自己加的方法调不到；接口名 `Jumpping` 拼写是错的（正确 Jumping），三处（接口定义、Cat7 实现、这里的引用类型）必须拼写完全一致，否则编译失败。
