# Animal74.java 总结

- 内容：一个空类骨架，只有 `public class Animal74 {}` 一行，里面没有任何成员变量和方法；文件头带 `package PACKAGE_NAME;`，是 IDEA 新建文件时自动生成的默认包声明占位符。
- 知识点：类的最小定义形式就是 `public class 类名 {}`，空类也能编译通过；类名后的数字 `74` 只是随手编号，没有任何语法含义（前面已有 Animal、Animal1～Animal6 等多个同系列练习文件）；多态练习里常见的套路是父类 `Animal` 加子类 `Cat`/`Dog`，再用 `Animal a = new Cat();` 做向上转型。
- 易错点：`package PACKAGE_NAME;` 是 IDEA 的占位包名，不是真实包，编译/运行时要改成实际包名或删掉，否则会报找不到包；空类现在什么都干不了，下一步要往里面加成员（比如 `eat()` 方法或 `name`、`age` 属性），再配合子类做多态练习；如果这个文件是想写“动物”相关的多态例子，注意别和已有的 Animal 系列文件里的类名、方法名搞混。
