# AnimalDemo7.java 总结

- 内容：测试类，演示抽象类 + 接口 + 多态的完整用法：`Jumpping1 j = new Cat8(); j.jump();`（接口引用调接口方法）、`Animal7 d = new Cat8();`（抽象父类引用指向子类对象，调 `setName`/`setAge`/`getName`/`getAge`/`eat()`）、再用有参构造 `new Cat8("xrs", 100)` 赋值给父类引用和本类引用 `Cat8 c`，最后用注释总结了类与接口的关系；注意 `d.jump();` 被注释掉了，因为父类引用调不到接口方法。
- 知识点：多态的两种引用写法——接口引用只能调接口里的方法，父类引用只能调父类里的方法，实际执行的是子类重写后的方法；成员变量、构造方法不能多态，只有方法能；类和接口的关系一共四种：类–类是继承（单继承、可多层）、类–接口是实现（可单实现、可多实现、还可以在继承一个类的同时实现多个接口）、接口–接口是继承（可单继承、可多继承）。
- 易错点：`d.jump();` 被注释掉不是笔误——`Animal7` 类型的引用 `d` 根本看不到 `jump()`，取消注释会编译报错，要调 jump 得用 `Jumpping1` 引用或 `Cat8` 本类引用；`d = new Cat8("xrs", 100);` 重新赋值后 name 是 `xrs`、age 是 `100`，输出是 `xrs 100`，不是第一次的 `xrs 18`；`getName()+" "+getAge()` 中间拼的是一个空格，输出格式是 `名字 空格 年龄`；`new Cat8()` 无参构造创建的对象 name 是 null、age 是 0，打印前必须先 set，否则输出 null 0。
