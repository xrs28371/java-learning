# InnerDemo.java 总结

- 内容：测试内部类的主类，但目前是个半成品草稿。`main` 方法里只有注释：一段被注释掉的直接创建内部类对象的写法 `Outer1.Inner o = new Outer1().new Inner(); o.show();`，以及一句没写完的注释“如果是 private 内容呢”。
- 知识点：外部其他类创建成员内部类对象的标准格式是 `外部类名.内部类名 对象名 = new 外部类名().new 内部类名();`，即先有外部类对象，再用它 `new` 内部类对象；`Outer1` 的内部类是 `private` 的，所以这行代码即使放开注释也编译不过——`private` 内部类只能在外部类内部访问，外部类必须提供方法（如 `Outer1.method()`）做入口。
- 易错点：这份代码目前没有可执行的语句，`main` 是空的，运行起来什么都不输出——别误以为它能演示内部类调用；笔试常考“`private` 内部类能不能在外部直接 `new`”，答案是不能，只能通过外部类提供的方法间接访问。
