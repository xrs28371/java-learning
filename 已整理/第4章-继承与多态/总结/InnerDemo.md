# InnerDemo.java 总结

- 内容：测试内部类的主类，现已补成可运行版本。`main` 方法里创建 `Outer1` 对象并调用 `o.method()`，通过外部类方法间接访问其 `private` 成员内部类并打印 `num`（输出 10）。文件里仍保留一段被注释掉的直接创建内部类对象的写法 `Outer1.Inner o = new Outer1().new Inner(); o.show();`，以及一句没写完的注释“如果是 private 内容呢”。
- 知识点：外部其他类创建成员内部类对象的标准格式是 `外部类名.内部类名 对象名 = new 外部类名().new 内部类名();`，即先有外部类对象，再用它 `new` 内部类对象；但 `Outer1` 的内部类是 `private` 的，所以注释里那行代码即使放开也编译不过——`private` 内部类只能在外部类内部访问，外部类必须提供方法（如 `Outer1.method()`）做入口。现在这份代码走的就是这条正确路线。
- 易错点：笔试常考“`private` 内部类能不能在外部直接 `new`”，答案是不能，只能通过外部类提供的方法间接访问；`new Outer1().new Inner()` 这种双 `new` 写法本身只对非 `private` 的成员内部类成立，别把格式背混——先 `new` 外部类对象，再用该对象 `new` 内部类。
