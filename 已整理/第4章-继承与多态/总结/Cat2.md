# Cat2.java 总结

- 内容：`public class Cat2 implements Jumpping`，实现接口 `Jumpping`，重写 `jump()` 输出 "Jumping Cat2"。整个类只有这一个方法，没有继承任何父类。
- 知识点：类实现接口。① `implements` 表示“实现”，类一旦实现接口，就必须重写接口里的全部抽象方法（否则类本身得声明为抽象类），这里只重写了唯一的 `jump()`；② 实现后 `Cat2` 对象可以被 `Jumpping` 类型的引用指向（接口多态），如 `Jumpping j = new Cat2(); j.jump();`，编译看左边、运行看右边；③ 与本章另一条线（Cat2 旧版继承 Animal2）对比：继承是 "is-a"（猫是一种动物），实现接口是 "has-ability"（猫具备会跳的能力），一个类可以只继承一个父类、但可以实现多个接口。
- 易错点：**本文件 2026-11-08 被整个改写过，文件名被重用于另一道练习**：旧版 `Cat2 extends Animal2`（重写 `eat()` 输出 "eat"，另有子类特有方法 `palygame()`）已不在本文件里，旧版已按规矩快照在同章节「历史版本」子夹 `Cat2-旧版-20261108-0904.java`，要找旧版去那里翻，别以为当前文件就是多态转型那一节的子类；`palygame` 本身也是拼写错误（应为 `playgame`），旧版总结里已记过。接口名 `Jumpping` 拼错（正确 Jumping），实现时必须原样照抄；`jump()` 前必须加 `@Override` 且保持 `public`，缩小访问权限会编译失败。
