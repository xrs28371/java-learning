# Inter.java 总结

- 内容：一个空接口的定义骨架，只有 `public interface Inter {}` 一行，里面没有任何方法、常量或成员。刚建好，还没往里面加内容，应该是跟着课件学接口定义时先搭的架子。
- 知识点：接口的最小定义形式就是 `public interface 接口名 {}`，空接口本身也能编译通过；接口里的方法默认是 `public abstract`，常量默认是 `public static final`，即使不写修饰符也一样；接口不能实例化，只能由实现类 `implements` 它以后再 `new` 实现类。
- 易错点：空接口现在什么都干不了——没有任何抽象方法可供实现类重写，也没有任何常量可供使用，`Inter` 引用调不到任何方法；如果只是想练“定义接口”，下一步要往里面加抽象方法（比如 `void jump();`），再写一个实现类去实现它；接口名 `Inter` 是 Interface 的缩写，随手取的，正式代码里建议用完整、见名知意的接口名。
