# Animal4.java 总结

- 内容：抽象类 `public abstract class Animal4`，只有一个抽象方法 `public abstract void eat();`，附注释「抽象类的定义」。相比旧版（空类）已补上抽象类定义。
- 知识点：抽象类与抽象方法。抽象类不能直接实例化，只能被继承；抽象方法只有方法声明、没有方法体，子类继承后必须实现它（除非子类也是抽象类）。这里 `eat()` 就是典型的“只定行为、不给实现”——不同动物吃东西的方式不同，留给子类各自实现。
- 易错点：笔试高频点——抽象方法不能有方法体（`eat();` 后面直接是分号，不能写 `{}` 空方法体）；抽象类里可以没有抽象方法，但有抽象方法的类一定是抽象类；`abstract` 不能和 `final`、`private`、`static` 一起修饰方法（final 要求不能重写、private 要求子类看不见，都和“等子类实现”冲突）。注意 Animal4 现在是抽象类，`new Animal4()` 编译报错。
