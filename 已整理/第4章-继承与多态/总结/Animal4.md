# Animal4.java 总结

- 内容：抽象类 `public abstract class Animal4`，含一个抽象方法 `public abstract void eat();`，新增一个普通方法 `public void sleep()`（输出 "sleep"），附注释「抽象类的定义」「抽象类里面可以有方法」。
- 知识点：抽象类与抽象方法。抽象类不能直接实例化，只能被继承；抽象方法只有方法声明、没有方法体，子类继承后必须实现它（除非子类也是抽象类）。**抽象类里可以有普通方法**：`sleep()` 就是带方法体的具体方法，子类继承后可直接调用，不用重写——抽象类不是“全是抽象方法”，它和普通类的区别只在“可以含抽象方法、不能实例化”。
- 易错点：笔试高频点——抽象方法不能有方法体（`eat();` 后面直接是分号，不能写 `{}` 空方法体）；抽象类里可以没有抽象方法，但有抽象方法的类一定是抽象类；`abstract` 不能和 `final`、`private`、`static` 一起修饰方法。注意 Animal4 现在是抽象类，`new Animal4()` 编译报错。
