# Outer.java 总结

- 内容：成员内部类的基本写法。外部类 `Outer` 有一个私有成员变量 `num = 10`，内部定义了 `public class Inner`，其 `show()` 方法直接打印外部类的 `num`；外部类提供 `method()` 方法，在内部 `new Inner()` 并调用 `i.show()`，作为访问内部类的入口。文件里还留了一段被注释掉的旧版 `method()`（直接写 `show()`，编译不过）。
- 知识点：成员内部类可以直接访问外部类的所有成员，包括 `private` 成员；外部类要访问内部类成员，必须先创建内部类对象；内部类对象依附于外部类对象存在。
- 易错点：注释掉的旧写法 `show();` 是错的——外部类的方法不能直接调用内部类的方法，必须先 `new Inner()` 再调；笔试若问“外部类如何访问内部类”，答案是创建内部类对象后调用，不能直接写方法名。
