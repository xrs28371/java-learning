# Cat5.java 总结

- 内容：`public class Cat5 extends Animal5`，继承抽象类 Animal5，只做一件事：用 `@Override` 重写抽象方法 `eat()`，方法体输出 "eat fish"，附注释「限定子类去重写」。
- 知识点：抽象方法的强制实现。抽象类 Animal5 里的 `eat()` 是抽象方法，普通子类 Cat5 继承后**必须**重写它，否则 Cat5 自己也得声明成抽象类。`@Override` 注解是给编译器检查的：方法签名写错（比如参数、返回值对不上）编译直接报错。配合 AnimalDemo5 的 `Animal5 a = new Cat5(); a.eat();`，运行时执行的是子类这个版本，输出 "eat fish"，这是多态最基本的演示。
- 易错点：笔试高频点——抽象方法必须被子类重写（除非子类也是抽象类）；重写时方法名、参数列表、返回值必须和父类一致，访问权限不能缩小（父类是 public，子类不能写成默认或 private）；`@Override` 写错位置或拼错会编译报错，它本身不是可选项、是防手滑的保险。
