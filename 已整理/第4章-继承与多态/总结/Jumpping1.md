# Jumpping1.java 总结

- 内容：接口 `Jumpping1`，内含一个抽象方法 `void jump();`，是 Cat8、Dog4 的“会跳”能力接口；相比上一版（空接口骨架），本次更新补上了 `jump()` 抽象方法，并删掉了 IDEA 自动生成的 `package PACKAGE_NAME;` 占位包声明。
- 知识点：接口里的方法默认就是 `public abstract`，写不写修饰符都一样，实现类必须重写它；接口不能实例化，只能用接口引用指向实现类对象（如 `Jumpping1 j = new Cat8();`）；一个类可以在继承一个类的同时实现多个接口，这是 Java 单继承之外的能力扩展口子。
- 易错点：接口名 `Jumpping1` 拼写有误，正确拼写是 `Jumping`（一个 p），`Jumpping` 是多打了一个 p——文件名和接口名必须完全一致，引用时要照抄这个错拼，改名要连文件带引用一起改；接口引用只能调接口里声明的方法，`j.jump()` 能调，`j.eat()` 不能调（eat 是父类 Animal7 的方法，不在接口里）。
