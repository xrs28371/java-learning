# Dog3.java 总结

- 内容：`public abstract class Dog3 implements Jumpping { //如果是抽象一样不用去重写方法 }`，一个抽象类实现了 Jumpping 接口，但类体是空的、没有重写 `jump()`。
- 知识点：抽象类实现接口可以不重写方法。① 普通类实现接口必须实现全部抽象方法，但**抽象类例外**——可以把 `jump()` 的实现责任推给自己的子类；② `abstract class` 哪怕一个抽象方法都不写也可以存在，它存在的意义是被继承、等子类去补全；③ 将来 Dog3 的某个非抽象子类（如 Dog4 extends Dog3）必须实现 `jump()`，否则它自己也得声明成抽象类。
- 易错点：抽象类“不用重写”是特权不是漏洞——普通类（不带 abstract）实现接口漏写方法会编译报错，别把两条规则记混；抽象类不能被实例化，`new Dog3()` 是错的；接口名 `Jumpping` 拼写是错的（正确 Jumping），必须原样照抄；注释“如果是抽象一样不用去重写方法”说的是这个特权，笔试简答题可以直接用这个点。
