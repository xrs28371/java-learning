# AnimalDemo2.java 总结

- 内容：测试类（main 方法），练「多态的转型」。先向上转型：`Animal2 a = new Cat2();`，调 `a.eat()`；再向下转型：`Cat2 c = (Cat2) a;`，调 `c.eat()` 和子类特有方法 `c.palygame()`；注释里还留了一段直接 new Cat2 的写法作对照。
- 知识点：向上转型（子→父，父类引用指向子类对象）和向下转型（父→子，父类引用转为子类对象）是笔试多态部分的必考点。向上转型后只能调父类有的方法，调不到子类特有功能；向下转型后才能调 `palygame()` 这类子类特有方法。`a.eat()` 输出的是子类 Cat2 重写后的方法（动态绑定），不是父类 Animal2 的。
- 更新说明（2026-11-07）：旧版最后一行是裸转换 `(Cat2)a`，单独成句是编译错误；新版已改成 `Cat2 c = (Cat2) a;` 再调方法，编译通过。
- 易错点：向下转型必须赋值给变量才能用，别只写个裸转换；向下转型前要确认 `a` 实际指向的就是 Cat2 对象，否则运行时会报 `ClassCastException`。另外注意代码里的 `palygame()` 拼写——game 前疑似拼写问题（应为 playGame 的意图），笔试手写时方法名以题目/父类定义为准，别凭记忆拼错。
