# AnimalDemo2.java 总结

- 内容：测试类（main 方法），练「多态的转型」。先向上转型：`Animal2 a = new Cat2();`，调 `a.eat()` 输出 "eat"；注释里还留了一段直接 new Cat2 调 `eat()` 和 `palygame()` 的写法；最后有一行向下转型的代码 `(Cat2)a`。
- 知识点：向上转型（子→父，父类引用指向子类对象）和向下转型（父→子，父类引用转为子类对象）是笔试多态部分的必考点。向上转型后只能调父类有的方法，调不到子类特有功能；向下转型后才能调 `palygame()` 这类子类特有方法。
- 易错点：**最后一行 `(Cat2)a` 单独成句是编译错误**：强制类型转换本身不是一条合法的语句，必须赋值给变量才能用，正确写法是 `Cat2 c = (Cat2) a;` 然后再 `c.palygame();`。笔试手写向下转型时一定记得写赋值、别只写个裸转换。另外注意 `a.eat()` 输出的是子类 Cat2 重写后的方法（动态绑定），不是父类 Animal2 的；向下转型前要确认 `a` 实际指向的就是 Cat2 对象，否则运行时会报 `ClassCastException`。
