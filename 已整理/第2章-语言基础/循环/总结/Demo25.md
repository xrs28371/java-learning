# Demo25.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：跳转控制语句 continue 与 break 的对照**

- 第一段：`for (int i = 0; i < 5; i++)`，遇到 `i % 2 == 0` 就 `continue`，跳过本次、继续下一次——只打印奇数 1、3。
- 第二段：`for (int i = 1; i < 5; i++)`，遇到 `i % 2 == 0` 就 `break`，直接中止整个循环——i = 1 时打印 1，i = 2 时触发 break，后面全不执行，所以只输出 1。

**关键结论**

- continue 是“跳过某一次、继续下一次”，循环还在；break 是“中止整个循环、没有下一次”，循环直接结束。
- 两段代码条件相同（`i % 2 == 0`）、循环范围几乎相同，输出却完全不同（1、3 vs 只有 1），对照起来正好说明两者的区别。

**笔试易错点**

- ⚠️ continue 和 break 混淆是必考点：问“输出什么”时先分清是跳过一次还是结束循环——continue 后的循环还会继续，break 后的循环体一次都不会再跑。
- continue 跳过的是“本次循环剩余的部分”，不是“本次循环的自增”：for 的 `i++` 在 continue 后仍会执行，不会卡死；但如果是 while 循环里把自增写在 continue 之后，continue 会跳过自增、造成死循环，写 while 版时要格外小心。
- break 只跳出它所在的“最内层”循环：嵌套循环里内层 break 只结束内层，外层继续跑；想一次跳出多层得用标签（笔试一般不考，但别误以为一个 break 能全停）。
- 本例第二段的输出只有 1：i = 2 时还没打印就 break 了——判断语句在打印之前，所以偶数本身不会被输出；如果把打印写在判断之前，结果就完全不同，读题时注意语句顺序。
