# Demo15.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：流程控制语句——顺序结构 + if 分支入门**

- 代码先用注释列出流程控制的三大结构：顺序结构、分支结构、循环结构，本例实现了前两种，循环尚未展开。
- 顺序结构演示：依次打印“开始”→ 三次“语句A” →“结束”，输出顺序与代码书写顺序完全一致，没有任何判断或跳转；这是 Java 的默认执行方式。
- if 语句格式 1（单分支）：`if (关系表达式) { 语句体; }`，条件成立才执行大括号里的语句。例：a=10、b=20 时 `a==b` 不成立不打印；c=10 时 `a==c` 成立，打印“a==c”。
- if-else 语句格式 2（双分支）：条件成立走 if 分支，否则走 else 分支，二选一必走其一。例：aa=10、bb=20 时 `aa>bb` 不成立，走 else 打印“aa<bb”。

**笔试易错点**

- 关系判断用 `==`，不是赋值 `=`；把 `a==b` 写成 `a=b` 会改变变量值且（int 类型）编译报错。
- else 没有自己的条件：它承接的是 if 条件不成立的全部情况。本例 else 打印“aa<bb”只是因为恰好 aa<bb，严格说 else 对应的是 `aa<=bb`，不能反推 else 分支就等于 `aa<bb` 这个条件。
- 三次打印的都是同一个字符串“语句A”，不是三个不同语句，默写时别把它当成 A/B/C 三个变量。
- 注释里的 `if（关系表达式）` 用的是中文全角括号，只是注释不影响编译；真正写代码时必须用英文半角括号 `()`。
