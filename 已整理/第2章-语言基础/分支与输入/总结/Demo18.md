# Demo18.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：if-else if-else 多分支——分数区间分档奖励**

- 用 Scanner 读入一个整数 score，按分数区间分档输出：95 分及以上打印“山地自行车”，90~94 打印“游乐场”，80~89 打印“变形金刚”，80 分以下打印“胖揍一顿”。
- 结构是 `if – else if – else if – else` 多分支链，注释已把思路点明：先排除非法，再对合法分数按区间判断。

**关键结论**

- 本版已重写旧版（旧版只是 `if (score <= 80)` 单分支）：现在先用 `if (score < 0 || score > 100)` 把非法分数挡在最前面打印“输入错误”，剩下的 0~100 再分档，非法输入不再被误当成低分处理。
- 区间判断只写下限即可：因为多分支“命中即停”，走到 `score >= 90` 时已排除了 >=95 的情况，所以不用再写 `score >= 90 && score < 95`；同理 `score >= 80` 实际只覆盖 80~89。
- 分支顺序必须从高到低：如果先写 `score >= 80`，95 分也会命中第一档，拿不到山地自行车——顺序写反是这类题最常见的逻辑错误。

**笔试易错点**

- 非法判断要用 `||`（或）：分数小于 0 **或者** 大于 100 都非法；写成 `&&` 则没有任何数能同时满足两个条件，校验永远失效。
- 区间边界：95、90、80 都是“大于等于”，95 分正好拿山地自行车、90 分正好去游乐场、80 分正好拿变形金刚；写成 `>` 则边界分会掉进下一档。
- 最后的 else 没有条件，承接的是 0~79 的合法低分，不是非法输入——非法输入已由第一个 if 拦下，不要把 else 理解成“输入错误”分支。
