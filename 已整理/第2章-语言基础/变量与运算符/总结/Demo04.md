# Demo04.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：运算符与表达式（算术运算符为主）**

- 概念注释：运算符是对常量/变量进行操作的符号；表达式是用运算符连接常量/变量的式子，`a + b` 是算术表达式。
- 算术运算：`a = 100`、`b = 20`，依次输出 `a + b`、`a - b`、`a * b`、`a / b`、`a % b`。注释强调整数运算只能得到整数结果，想要小数必须有浮点数参与。
- 表达式自动类型提升：`int i = 10` 与 `char e = 'A'` 相加，`'A'` 先按 ASCII（65）提升为 int，结果用 int 接收（`i + e = 75`）。注释给出提升顺序：byte、short、char → int → long → float → double。
- 字符串的 `+` 操作：字符串与字符串拼接（`"cjh" + "xrs"`），字符串与整数拼接（`"xrs" + 666666`，整数被转成字符串）；后补了一个数字在前的例子（`666666 + "xrs"`），只要有一边是字符串，`+` 就是拼接，与顺序无关。
