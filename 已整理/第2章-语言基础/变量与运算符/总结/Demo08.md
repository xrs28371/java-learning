# Demo08.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：逻辑运算符（&、|、^、!）**

- 测试值：`i = 10`、`j = 20`、`k = 30`，用 `(i>j)`、`(i<k)` 等关系表达式的真假组合逐个验证。
- `&`（与）：四个组合都试了，结论注释已写明——**都是 true 才为 true**。
- `|`（或）：**有 true 就为 true，都 false 才为 false**。
- `^`（异或）：**相同为 false，不同为 true**。
- `!`（非）：`(i>j)` 为 false，`!(i>j)` 为 true，即取反。
- 注意：本文件练的是单符号 `&`、`|`（两边都会算），双符号 `&&`、`||` 的短路区别还没有写进来——那是自测单 (b) 题的考点，别漏。
