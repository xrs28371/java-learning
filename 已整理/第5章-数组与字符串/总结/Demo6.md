# Demo6 总结

## 练的知识点
- String 遍历应用（第5章-数组与字符串）：统计一个字符串中大写字母、小写字母、数字各有多少个——`Scanner` 读入 + `for + charAt` 遍历 + 字符范围判断 + 计数器累加的组合题。

## 关键结论
- 思路：三个计数器 `bigcount`、`smallcount`、`numbercount` 初始都为 0；遍历每个字符，用范围判断归类，对应计数器 `++`；最后分别输出三类个数。
- 范围判断靠字符比较：大写 `ch >= 'A' && ch <= 'Z'`，小写 `ch >= 'a' && ch <= 'z'`，数字 `ch >= '0' && ch <= '9'`——利用的是字母和数字在字符编码中连续排列这一前提。
- 用 `else if` 链串联三类判断：一个字符最多只属于一类，命中一类后不再往下判断，既省判断又保证不会重复计数。

## 笔试易错点
- 除三类之外的字符（如空格、标点、中文）不会被任何一分支命中，直接被跳过不计数——所以三类个数之和不一定等于字符串总长度，笔试若问「其余字符去哪了」，答案就是「没统计、直接忽略」。
- 范围端点必须写全 `>=` 和 `<=`：只写一端会把范围外的字符误算进来；`'A'`、`'a'`、`'0'` 的单引号不能丢，写成双引号就变成字符串、无法与 `char` 比较，编译直接报错。
- 计数器必须在循环外定义并初始化为 0：定义在循环内会被每轮重置，永远只能数到 1；漏写初始值则编译报错（局部变量使用前必须赋值）。
- 输出文案有小瑕疵：第二行「小写字母」后漏了中文冒号（第一、三行都有），不影响运行，但笔试按输出结果填空时要按代码实际输出写，不能自行补全。
