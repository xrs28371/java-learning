# Demo20 总结

## 练的知识点
- 测试类写法：`main` 方法里创建对象，验证 Teacher 类的两种构造方法。
- 无参构造＋setter 赋值：`new Teacher()` 后用 `setName("xrs")`、`setAge(20)` 逐个设值。
- 有参构造一步到位：`new Teacher("xrs", 33)` 创建即赋值。

## 关键结论
- Demo20 现在是 Teacher 封装练习的完整测试入口：两种构造方式都跑了一遍，分别用 `getName()` / `getAge()` 打印验证。
- **本次更新修好了旧版的编译坑**：旧版只有 `new Teacher();` 一行，当时 Teacher 没有无参构造，编译不过；现在 Teacher 补了显式无参构造，`new Teacher()` 已能正常编译；同时新增了有参构造的测试 `t2`。

## 笔试易错点
- 定义了有参构造后默认无参构造消失，是第 4 章构造方法部分的必考坑——Teacher 现在是“显式补无参构造”的标准解法，记住这个对照关系。
- `t1` 和 `t2` 是两个独立对象：`t1` 用无参＋setter（name 是 "xrs"、age 是 20），`t2` 用有参构造（name 是 "xrs"、age 是 33），两者互不影响；笔试若问输出，要分开算。
- 注意：文件按章节路由表归入第 5 章文件夹，但 Demo19/Demo20 这一批实际练的是第 4 章继承/方法重写与构造方法，复习时按知识点找、不要只按文件夹认章节。
