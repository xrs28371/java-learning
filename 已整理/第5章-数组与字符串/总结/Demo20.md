# Demo20 总结

## 练的知识点
- 测试类写法：`main` 方法里创建对象，验证 Teacher/Student 两个类的构造方法。
- 有参构造方法的调用：`new Teacher(...)` 必须传参。

## 关键结论
- Demo20 现在是 Teacher/Student 封装练习的测试入口：`main` 里 `Teacher t1 = new Teacher();` 想用无参构造创建对象。

## 笔试易错点
- **这行代码目前编译不过**：Teacher 只定义了 `Teacher(String name, int age)` 有参构造，编译器不再自动提供无参构造，`new Teacher()` 会报“找不到符号/无法将构造方法应用于给定类型”之类的编译错误。正确写法是 `new Teacher("张三", 20)`，或者给 Teacher 再补一个无参构造。
- 这是笔试高频考点：定义了有参构造后默认无参构造消失，是第 4 章构造方法部分的必考坑。
