# Demo24 总结

## 练的知识点
- `final` 修饰基本类型变量：`final int age = 20;`，一旦赋值就不能再改，`age = 21;` 会编译报错。
- `final` 修饰引用类型变量：`Student s1 = new Student();`，`final` 锁住的是**引用（地址）本身**，不能再让 `s1` 指向另一个对象；但对象内部的状态仍可通过 setter 改（`s1.setAge(...)` 是合法的）。
- 配合 Student 类做实验：代码里被注释掉的 `s1.age = 100;` 即使放开也会编译失败——`age` 是 `private` 字段，类外不能直接访问，只能走 `setAge()`。

## 关键结论
- `final` 的核心就一句话：**基本类型锁值，引用类型锁地址、不锁对象内容**。这是笔试高频考点。
- 本次更新把空 `main` 骨架填成了 final 的验证代码：先演示基本类型、再演示引用类型，注释里“加了 final 地址没有办法改变”指的就是引用不可重新指向。

## 笔试易错点
- `final` 修饰的变量只能赋值一次；基本类型是值不能变，引用类型是地址不能变、对象内部属性照样能改——两者不要混淆。
- `final` 修饰的引用变量不能重新赋值（`s1 = new Student();` 第二次就报错），但 `s1.setAge(100)` 不报错。
- `private` 字段类外不可直访：`s1.age` 写法本身就是错的，哪怕没有 `final` 也一样编译不过，要用 `getAge()` / `setAge()`。
- 注释“地址里面”没写完、表意不清；写代码时注释要写完整，否则复习时自己都看不懂。
