# Demo8 总结

## 练的知识点
- String 反转（第5章-数组与字符串）：键盘录入一个字符串，调用方法后输出反转结果，例如输入 `abc` 输出 `cba`——`Scanner` 读入 + 方法定义（参数 `String`、返回值 `String`）+ 倒序 `for` 遍历 + `charAt` 取字符 + 字符串拼接的组合题。

## 关键结论
- 反转的核心就一行思路：从 `s.length() - 1` 倒着遍历到 `0`，每次用 `s.charAt(i)` 取出字符拼到新串 `ss` 上，循环结束返回 `ss`。
- `main` 四步齐全：`Scanner` 读入 → 调用 `rev(line)` → 用变量接收返回值 → 输出，缺一步结果都出不来。
- 倒序循环的起止点是这道题的考点：起点必须是 `length() - 1`（最后一个字符下标），终点是 `0`（含），步长 `-1`；写成从 `length()` 开始会下标越界，写成 `i > 0` 会漏掉首字符。

## 笔试易错点
- 循环内用 `ss += s.charAt(i)` 拼接：逻辑正确、笔试够用，但每次拼接都会产生新字符串，效率低；实际开发会用 `StringBuilder`，笔试按题目要求写即可，不必炫技。
- `Scanner` 用 `nextLine()` 读整行（含空格），若误写成 `next()` 则空格后的内容会被截断；题目说「录入一个字符串」时要按实际输入是否含空格选方法。
- 代码里 `Scanner` 用完未 `close()`：不影响运行和笔试得分，但规范写法应在最后 `sc.close()`；注意一旦 `close()`，后续再用该 `Scanner` 读入会报错。
