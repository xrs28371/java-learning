# Fu7 总结

## 练的知识点
- `final` 修饰方法：`public final void method()`，打印 "Fu method"；`final` 方法不能被子类重写。
- `final` 修饰类（注释里被注释掉的写法）：`public final class Fu7`，一旦这样写，这个类就不能被任何类继承——注释末尾“被如上修饰无法被继承”指的就是这一条。

## 关键结论
- `final` 方法可以被子类继承、直接调用，但子类里写一个同名同参数的方法就是重写，会编译报错。
- `final` 类没有子类，所以它里面的方法天然也不会被重写；但 `final` 类本身照常可以继承别的类（除非父类也是 `final`）。
- 这份代码是 Zi7 的“被测试父类”：Zi7 继承 Fu7，验证的正是“父类 `final` 方法 + 子类 `final` 变量”这一组规则。

## 笔试易错点
- **注释说法要抠准**：“final 不可以被重写”只对 `final` 方法成立；`final` 类是“不可以被继承”，`final` 变量是“不可以再赋值”，三句话别混成一句（见 Demo23）。
- `final` 方法可以被重载（同名不同参数），不能被重写——笔试常把重写和重载放一起考。
- 文件里 `public final class Fu7` 那段是被注释掉的**反例写法**：如果取消注释，Zi7 的 `extends Fu7` 立刻编译报错，因为 `final` 类不能被继承——这是笔试最爱考的“注释掉的代码一旦放开会怎样”。
