# Zi 总结

## 练的知识点
- 类的继承（第5章-数组与字符串归档；内容实际是第6章继承部分）：`public class Zi extends Fu`，Zi 是 Fu 的子类。
- 子类扩展父类功能：Zi 自己新增一个实例方法 `method()`，打印 "method方法被调用"；同时从父类继承了 `show()`。

## 关键结论
- 继承后子类拥有的方法 = 父类的方法 + 自己定义的方法：Zi 对象既能调 `method()` 也能调 `show()`（见 Demo14：`z.method(); z.show();` 两行都成立）。
- `extends` 是 Java 实现继承的关键字，写在子类类名之后、父类类名之前。

## 笔试易错点
- 文件首行 `import javax.swing.*;` 完全没用到——代码里没有任何 Swing 类，属于随手粘贴留下的冗余导入。编译不报错，但笔试/代码审查里是减分项，写代码时应删掉，只保留真正用到的 import。
- Java 是单继承：一个类只能 `extends` 一个父类，写 `extends Fu, Xxx` 编译不过；想多继承功能要走接口（接口可多实现）。
- 子类没有重写 `show()`，所以 `z.show()` 执行的是父类 Fu 里的原版；如果子类也写一个同签名的 `show()`，那才是方法重写、执行子类版。
- 注意：这份代码练的是继承，路由表把它归到了"第5章-数组与字符串"，按考试范围它实际属于继承章节，复习时按继承归类、不要按文件夹名死记。
