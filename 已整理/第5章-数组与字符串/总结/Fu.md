# Fu 总结

## 练的知识点
- 父类的定义（第5章-数组与字符串归档；内容实际是第6章继承部分）：`public class Fu`，定义一个无参无返回值的实例方法 `show()`，打印 "show方法被调用"。
- 作为被继承的类：Fu 本身不继承任何类，只提供一个可供子类继承的方法。

## 关键结论
- 父类的方法一旦定义，子类继承后无需重写即可直接调用（见 Demo14：`Zi` 对象能直接调 `z.show()`，执行的就是 Fu 里这个版本）。
- 这是 Demo14 继承演示的"父类"一端：Fu + Zi + Demo14 三个文件是一组，单独看 Fu 只有一个方法。

## 笔试易错点
- 类名与文件名必须一致：`public class Fu` 必须放在 Fu.java 里，否则编译报错。
- `void` 表示方法没有返回值，方法体里不能出现 `return 具体值`。
- 注意：这份代码练的是继承，路由表把它归到了"第5章-数组与字符串"，按考试范围它实际属于继承章节，复习时按继承归类、不要按文件夹名死记。
