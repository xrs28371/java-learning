# Demo3 总结

## 练的知识点
- 程序骨架（第5章-数组与字符串）：目前仅是一个空的 Java 程序框架，尚未写入任何业务逻辑。

## 关键结论
- 代码结构：`public class Demo3` + `public static void main(String[] args)`，是标准的主方法入口骨架，类名与文件名一致。
- `main` 方法体为空：程序可以正常编译、运行，但运行时什么都不做、没有任何输出，属占位文件，推测是下一个练习的起点。

## 笔试易错点
- 空 `main` 不是错误：没有输出不等于编译失败，笔试中问「程序运行结果」时答案是「无输出」，不要凭空补一个结果。
- 主方法签名必须一字不差：`public static void main(String[] args)`，缺 `static`、缺 `String[] args` 都会导致程序无法作为入口运行。
- 类名与文件名必须一致：`Demo3.java` 里的公开类只能是 `Demo3`，改名时文件与类要同步改。
