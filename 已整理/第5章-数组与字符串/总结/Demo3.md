# Demo3 总结

## 练的知识点
- String 比较（第5章-数组与字符串）：`==` 与 `equals()` 的区别，以及构造方法创建与直接赋值创建的字符串对象在内存上的不同。

## 关键结论
- `==` 的规则：基本类型比数据值，引用类型比地址值。字符串是对象，用 `==` 比的是是不是同一个对象，不是内容是否相同。
- `equals()` 的规则：字符串对象用 `equals()` 比内容，本例三个对象的内容都是 `"abc"`，所以三组 `equals` 结果全是 `true`。
- 创建方式决定地址：`new String(chs)` 两次调用在堆里建了两个不同对象，所以 `s1 == s2` 为 `false`；直接赋值 `"abc"` 走字符串常量池、相同字面量共用同一对象，所以 `s3 == s4` 为 `true`。
- 构造对象与字面量对象地址不同：`s1`（`new` 出来）与 `s3`（字面量）即使内容相同，`s1 == s3` 也是 `false`。
- 本程序运行结果（按顺序）：`false`、`false`、`true`、分隔线 `---------`、`true`、`true`、`true`。

## 笔试易错点
- 最容易错的一题就是 `s1 == s2`：内容相同不等于 `==` 为真，`new` 了两次就是两个地址，必须答 `false`；只有 `equals` 才答 `true`。
- 字面量相同就共享：`s3 == s4` 答 `true` 的依据是常量池共享，不是「碰巧内容一样」。
- 不要把 `==` 和 `equals` 的规则记反：`==` 比地址、`equals` 比内容，题目问「字符串内容是否相同」时只能用 `equals` 判断。
- 构造方法细节：`new String(char[] chs)` 是把字符数组 `{'a','b','c'}` 转成字符串 `"abc"`，不是把数组本身当字符串用。
