# Demo7 总结

## 练的知识点
- 数组与方法结合（第5章-数组与字符串）：把 `int` 数组按指定格式拼接成字符串返回，例如 `{1,2,3}` 拼成 `"[1,2,3]"`——方法定义（参数 `int[]`、返回值 `String`）+ `for` 遍历数组 + 字符串拼接的组合题。

## 关键结论
- 本轮更新后这份代码已是完整可运行版本：`arry` 方法内先拼 `"["`，循环逐个拼元素，最后拼 `"]"` 并 `return s;`，`main` 里定义数组、调用方法、用变量接收返回值再输出，四步齐全，输出 `[1,2,3]`。
- 末尾逗号的处理：用 `if (i == arr.length - 1)` 单独处理最后一个元素（只拼元素不拼逗号），其余元素拼完元素再拼 `","`，保证最后一个元素后无多余逗号。
- 对照上一版：旧版缺 `return`、循环分支是空的、`main` 没调用方法，属未完成半成品；本轮三处全部补齐，已可当作正确示例。

## 笔试易错点
- 方法名 `arry` 疑似 `array` 的拼写错误：不影响编译（方法名只要定义与调用一致即可），但笔试手写时建议写规范的方法名，避免被当成笔误。
- 注释里的示例 `int[]arr={1,2,3);` 括号不匹配（`{` 配了 `)`），只是注释不影响编译，但照抄进代码就是语法错误；真正的代码里 `int arr[] = {1,2,3};` 写法是对的（`int[] arr` 与 `int arr[]` 等价）。
- 有返回值的方法必须在所有路径上 `return`：漏 `return s;` 编译直接报错，这是旧版犯过的错，复习时要对照记住。
- 边界检查：空数组应输出 `[]`（循环不执行，直接拼 `"["` + `"]"`）；单元素数组输出 `[1]`，无逗号问题。
