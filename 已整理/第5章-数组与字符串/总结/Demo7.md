# Demo7 总结

## 练的知识点
- 数组与方法结合（第5章-数组与字符串）：把 `int` 数组按指定格式拼接成字符串返回，例如 `{1,2,3}` 拼成 `"[1,2,3]"`——方法定义（参数 `int[]`、返回值 `String`）+ `for` 遍历数组 + 字符串拼接的组合题。
- 思路本身是对的：先拼 `"["`，再逐个拼元素，元素之间用 `,` 分隔，最后拼 `"]"`；最后一个元素后不加逗号，要用 `i == arr.length - 1` 单独处理。

## 关键结论
- 格式拼接的标准写法：循环内先拼元素，`if (i == arr.length - 1)` 拼 `"]"`，否则拼 `","`；或者循环内只拼元素和逗号（末尾元素除外），循环结束后再拼 `"]"`。
- `main` 里要完成「定义数组 → 调用方法 → 用变量接收返回值 → 输出」四步，缺一步结果都出不来。
- 字符串拼接用 `s += ...` 累加即可；注意这份代码里 `s` 一开始就是 `""`，先 `s += "["`，后续元素和 `"]"` 都要往同一个 `s` 上累加。

## 笔试易错点
- **这份代码目前是未完成、编译不通过的半成品，不能直接当作正确示例背：**
  - `arry` 方法声明了返回值类型 `String`，但方法体内没有任何 `return` 语句——有返回值的方法必须在所有路径上返回，缺 `return s;` 编译直接报错。
  - 循环体内 `if (i == arr.length - 1)` 的分支是空的，`else` 分支根本没写：元素本身、逗号、`"]"` 全都没拼进去，即使补上 `return`，结果也只会是 `"["`。
  - `main` 里定义了 `arr` 却从没调用 `arry(arr)`、也没输出结果——方法写了不调用等于没写，控制台什么都不会打印。
- 方法名 `arry` 疑似 `array` 的拼写错误：不影响编译（方法名只要调用时一致即可），但笔试手写时建议写规范的方法名，避免阅卷时被当成笔误。
- 注释里的示例 `int[]arr={1,2,3);` 括号不匹配（`{` 配了 `)`），只是注释不影响编译，但照抄进代码就是语法错误；真正的代码里 `int arr[] = {1,2,3};` 写法是对的（`int[] arr` 与 `int arr[]` 等价）。
- 补全后应验证：输入 `{1,2,3}` 输出 `[1,2,3]`，且最后一个元素后无多余逗号；空数组应输出 `[]`，这是这类题最常见的边界检查点。
