# Fu5 总结

## 练的知识点
- 继承中的父类定义：`Fu5` 作为父类，提供一个带参数的方法 `call(String name)`。
- 方法重写的练习素材：父类方法供子类重写，练习"沿袭父类功能、加子类特有内容"。

## 关键结论
- `Fu5.call(String name)` 打印"给" + name + "打电话"，例如 `call("张三")` 输出"给张三打电话"。
- 本文件是 `Demo19` 方法重写练习的父类部分：子类 `Zi5` 预计要重写 `call()`，在保留"打电话"功能的基础上加入自己的内容。
- 目前 `Zi5` 还是空类壳、`Demo19` 里只创建了 `Fu5` 对象还没调用方法，这组练习还没写完。

## 笔试易错点
- 带参数方法的重写：子类重写时参数列表必须与父类完全一致（`String name`），参数名可以不同，但类型和个数不能变。
- 字符串拼接顺序："给"+name+"打电话"，输出题注意 `name` 的值插在中间，不要漏掉或写错位置。
- 注意类名与文件名一致：`public class Fu5` 必须放在 `Fu5.java` 里。
