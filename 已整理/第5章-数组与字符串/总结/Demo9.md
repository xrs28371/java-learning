# Demo9 总结

## 练的知识点
- 暂无：本轮同步时这份文件只有一个空类骨架 `public class Demo9 {}`，没有任何字段、方法（连 `main` 都没有）和逻辑，判断不出在练哪个知识点。

## 关键结论
- 空类本身可以编译通过，但运行它什么都不会发生——没有 `main` 方法，JVM 找不到程序入口，执行时会报「找不到主方法」类错误。
- 最可能的情形是刚新建文件、还没开始写题的占位符：文件名 Demo9 按顺序接在 Demo8 之后，属第5章-数组与字符串的新题起手文件，待下次同步有内容后再补总结。

## 笔试易错点
- 不要把空骨架当成已完成：复习时跳过它即可，等它长出 `main` 和方法体后再按实际代码更新本总结。
- 新建类时容易漏写 `main` 就直接运行：先确认类里有 `public static void main(String[] args)` 再运行，否则会误以为代码报错。
