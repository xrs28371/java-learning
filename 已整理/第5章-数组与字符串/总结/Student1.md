# Student1 总结

## 练的知识点
- `static` 修饰成员变量：`public static String university;`，`university` 不再属于某个对象，而是属于 `Student1` 这个类、被所有对象共享。
- 对照：`name`、`age` 是普通实例变量，每个对象各有一份；`university` 是静态变量，全班（所有对象）只有一份。
- `show()` 是非静态成员方法，方法里直接用 `university`——非静态方法可以访问静态成员变量。

## 关键结论
- 静态变量的核心就一句话：**属于类、不属于对象，所有对象共享同一份**。改一次，所有对象看到的都变了。
- 配合 Demo25 验证：`Student1.university = "xxxxxx"` 只赋值一次，s1、s2 两个对象 `show()` 出来的学校都一样，就是共享的证据。
- 被注释掉的 `//public String university;` 是改成 `static` 之前的普通写法，对比看就明白 `static` 加上去之后变量的归属变了。

## 笔试易错点
- 静态变量用类名访问：`Student1.university`，不要写成 `s1.university`——代码里 `//s1.university="xxxx";` 被注释掉就是这个原因，虽然语法上能通过对象访问静态成员，但规范写法是类名，笔试常考。
- 静态变量只有一份：给 `s1` 改了 `university`，`s2` 看到的也跟着变；如果误以为每个对象各有一份，笔试选择题必错。
- 非静态方法能访问静态变量，反过来不行：静态方法里不能直接用 `name`、`age` 这类实例变量，因为静态方法执行时可能还没有任何对象。
