# Demo5 总结

## 练的知识点
- String 遍历（第5章-数组与字符串）：键盘录入一个字符串，用 `Scanner.nextLine()` 读入，先输出字符串长度，再用 `for` 循环配合 `charAt(i)` 逐个输出每一个字符。

## 关键结论
- 遍历三要素：长度用 `字符串对象.length()`（带括号的方法），取字符用 `charAt(int index)`（索引从 0 开始），循环标准写法是 `for (int i = 0; i < line.length(); i++)`。
- 长度写法要区分：数组的长度是属性 `数组名.length`（无括号），字符串的长度是方法 `字符串对象.length()`（有括号）——两者一字之差，笔试最爱混考。
- 本轮更新：上一版只有注释、没有可执行代码，本版补上了 `Scanner` 读入、`length()` 输出和 `for + charAt` 遍历，遍历字符串这道题至此才算真正练完。

## 笔试易错点
- 注释里仍有两个笔误，照抄会错：`publicint length()` 中间漏了空格，应为 `public int length()`；「字符串对象.length0」多了一个 `0`，应为 `字符串对象.length()`——抄笔记时要按修正后的写法记。
- 循环条件必须用 `< length()` 而不是 `<= length()`：索引最大是 `length() - 1`，写成 `<=` 会在最后一次取 `charAt(length())` 时越界抛异常。
- `charAt` 的参数是索引、返回值是 `char`；`nextLine()` 读整行（含空格），若改成 `next()` 则空格后的内容会被截断，读字符串题要先看清用哪个方法。
