# Demo5 总结

## 练的知识点
- String 遍历的前置笔记（第5章-数组与字符串）：遍历字符串要解决的两个问题——拿到每一个字符、拿到字符串长度，对应 `charAt(int index)` 和 `length()`。

## 关键结论
- 遍历思路：索引从 0 开始，用 `charAt(i)` 取第 `i` 个字符，配合 `length()` 得到的长度控制循环结束，标准写法是 `for (int i = 0; i < str.length(); i++)`。
- 长度写法要区分：数组的长度是属性 `数组名.length`（无括号），字符串的长度是方法 `字符串对象.length()`（有括号）——两者一字之差，笔试最爱混考。
- 当前文件只有注释、没有可执行代码：没有 `Scanner` 读入、没有循环、没有输出，编译能过、运行后无任何输出，真正的遍历实现还没写。

## 笔试易错点
- 注释里有两个笔误，照抄会错：`publicint length()` 中间漏了空格，应为 `public int length()`；「字符串对象.length0」多了一个 `0`，应为 `字符串对象.length()`——抄笔记时要按修正后的写法记。
- 只记方法名不够：`charAt` 的参数是索引、返回值是 `char`；索引越界（`>= length()`）会抛异常，循环条件必须用 `< length()` 而不是 `<= length()`。
