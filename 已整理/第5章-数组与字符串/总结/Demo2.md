# Demo2 总结

## 练的知识点
- String 基础（第5章-数组与字符串）：字符串对象的特点与四种创建方式——空构造、字符数组构造、字节数组构造、直接赋值。

## 关键结论
- 字符串的特点：① 不可变，创建后值无法被改变；② 字符串可以被共享（常量池，相同字面量共用同一对象）；③ 效果上相当于字符数组，底层是字节数组（`byte[]`）。
- 四种构造方法：`new String()` 得到空字符串 `""`；`new String(char[])` 由字符数组 `{'a','b','c'}` 得到 `"abc"`；`new String(byte[])` 由字节数组 `{92,34,23,42}` 按默认字符集解码得到字符串；直接赋值 `String s4 = "abc";` 最常用。
- 本例推荐写法：直接赋值得到字符串对象，不必每次都 `new`。
- 输出方式：本例全部用 `print` 而非 `println`，四个结果会连在同一行输出，中间没有换行。

## 笔试易错点
- String 不可变不等于变量不可改：`s = "新值"` 是让变量指向新对象，原对象本身没有被修改；不要写成「字符串变量不能重新赋值」。
- 直接赋值与 `new String()` 的区别：字面量 `"abc"` 进字符串常量池、可共享；`new String("abc")` 一定在堆里新建对象，两者用 `==` 比较结果不同（`equals` 比较内容才相等）。
- `new String(byte[])` 按平台默认字符集解码，字节值与字符的对应关系依赖字符集，任意字节数组不一定能还原成可读字符；笔试中出现字节数组构造时要先看字节值再推断结果。
- 注释笔误：代码注释「题目可以被共享」应为「字符串可以被共享」，抄注释时不要原样照搬错字。
- `print` 与 `println` 混淆：本例用 `print`，若题目问输出格式，答案是四段结果连在一行，而不是每段各占一行。
