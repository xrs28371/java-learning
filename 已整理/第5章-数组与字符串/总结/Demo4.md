# Demo4 总结

## 练的知识点
- String 应用（第5章-数组与字符串）：「用户登录」案例完整版——预设用户名和密码，用 `Scanner.nextLine()` 读入用户输入，再用 `equals()` 比对，配合 `for` 循环给 3 次登录机会。

## 关键结论
- 流程：预设一组用户名和密码；`for (int i = 0; i < 3; i++)` 循环 3 次，每次读入账号和密码，两者都用 `equals()` 比对通过才算成功。
- 剩余次数用 `2 - i` 算：第 1 次失败剩 2 次、第 2 次失败剩 1 次、第 3 次（`i = 2`）失败时 `2 - i == 0`，输出「账户已锁定」。
- 比对写法是 `预设值.equals(输入值)`：字符串内容比较必须用 `equals()`，不能用 `==`（`==` 比的是地址，内容相同也可能判不相等）。

## 笔试易错点
- 登录成功后没有 `break`：当前代码成功输出后不会跳出循环，会继续要求输入直至 3 次用完——完整登录逻辑应在成功分支里加 `break`，这是本题最大的逻辑缺口，笔试改错/补全题要先看这一点。
- 变量名拼写要留神：输入变量写成了 `usename`（应为 `username`）、`psd`，以及输出里写的是「登陆成功」（应为「登录」）——变量名只要前后一致就能编译，但笔试填空/改错时按规范写法会被扣分，抄写时别跟着错拼。
- `Scanner` 建在循环体内：每次循环都 `new Scanner(System.in)`，虽能跑，但规范写法是循环外建一个、循环内复用；笔试问资源/规范时这是一个可指出的小问题。
- 次数算式别硬背：`2 - i` 的 2 是「总次数 3 减 1」，换成 5 次机会时应改为 `4 - i`；理解「剩余 = 总次数 - 已用次数 - 1」比背公式可靠。
