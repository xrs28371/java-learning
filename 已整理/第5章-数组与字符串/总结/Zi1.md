# Zi1 总结

## 练的知识点
- 继承中同名成员变量的访问（就近原则）：`Zi1 extends Fu1`，子类自己有 `age=20`、父类有 `age=40`，`show()` 方法里还有局部变量 `age=30`。
- 成员变量与局部变量的区分：方法内 `int age = 30;` 是局部变量，只在 `show()` 里有效。
- 子类新增成员变量：`public int height = 175;` 是 Zi1 自己独有的，父类 Fu1 里没有。

## 关键结论
- `show()` 里 `System.out.println(age)` 输出 30：按就近原则，方法内部先找局部变量，局部变量 age=30 优先，父类和子类成员变量都轮不上。
- `System.out.println(height)` 输出 175：`height` 只在子类里有，方法内没有同名局部变量，就用子类的成员变量。
- 注释里被注释掉的 `System.out.println(weight)` 会报错：`weight` 既不在方法内，也不在子类和父类里，三处都找不到这个变量，编译不通过——这正是"先方法内、再子类成员、最后父类成员"查找顺序的反面例证。

## 笔试易错点
- 同名变量三层查找顺序是笔试高频考点：局部变量 → 本类成员变量 → 父类成员变量。Demo15 的注释"先在方法内部、子类成员找、父类成员找"就是这个顺序的口诀。
- 局部变量优先于成员变量：`age` 在方法内是 30，不要答成子类成员的 20，更不要答成父类的 40。
- 子类成员变量和父类同名时，子类变量"隐藏"父类变量：直接写 `age` 拿到的是子类的 20（在没有局部变量的前提下），想拿父类的 40 要用 `super.age`（见 Zi2）。
- 注意：这份代码练的是继承，路由表把它归到了"第5章-数组与字符串"，按考试范围它实际属于继承章节，复习时按继承归类、不要按文件夹名死记。
