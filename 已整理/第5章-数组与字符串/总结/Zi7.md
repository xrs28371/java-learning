# Zi7 总结

## 练的知识点
- `final` 修饰成员变量：`public final int age = 20;`，`final` 变量一旦赋值就不能再改，`show()` 里被注释掉的 `age = 100;` 就是反例。
- 继承 + `final` 方法的组合：`Zi7 extends Fu7`，父类 Fu7 的 `method()` 是 `final` 方法，子类可以直接继承使用，但不能重写。
- 本轮更新：`show()` 里补上了 `System.out.println(age);`，现在调用 `show()` 会实际输出 `20`，把“final 变量的值”从只看代码变成了能跑出来的结果。

## 关键结论
- `final` 修饰的成员变量是常量：必须在声明时（像这里 `= 20`）或构造器里赋值，之后任何再赋值都会编译报错——`age = 100;` 被注释掉就是因为放开它就编不过。
- 子类继承父类的 `final` 方法后，调用没问题，重写不行；这份代码没有写重写尝试，所以只验证了“能继承”，没验证“重写报错”那一半。
- `show()` 现在的输出是固定的 `20`：`age` 是 `final`，改不了，`println` 每次都印同一个值。

## 笔试易错点
- **“final 变量不能改”要分清两种改法**：`final` 修饰基本类型变量是值不能改；`final` 修饰引用类型变量是引用（指向）不能改，但对象内部的状态可以改——笔试常考这个区别。
- `final` 成员变量如果只声明不赋值、也不在构造器里赋值，编译直接报错；局部 `final` 变量也一样，用之前必须赋值。
- `final` 方法不能被重写，但**可以被重载**；子类里同名不同参数的方法是重载，不是重写，不报错。
