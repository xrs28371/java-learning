# Demo31 总结

## 练的知识点
- 数组的**静态初始化**：`int arr[] = {1, 2, 3};` 定义时直接给元素，长度由元素个数决定。
- 输出对照：`System.out.println(arr)` 打印的是数组引用（地址样式），逐个下标 `arr[0]`、`arr[1]`、`arr[2]` 才打印元素 1、2、3。

## 关键结论
- 静态初始化不用写 `new`，也不用先定长度。
- 打印数组名永远得不到元素内容，要遍历或按下标取。

## 笔试易错点
- 两种写法都合法：`int[] arr = {1,2,3}` 与 `int arr[] = {1,2,3}`。
- 静态初始化不能既写长度又写值：`new int[3]{1,2,3}` 是语法错误。
- 简写 `{1,2,3}` 只能在声明同时初始化；先声明后赋值必须写 `arr = new int[]{1,2,3};`。
