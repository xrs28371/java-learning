# Demo47 总结

## 练的知识点
- 对象引用赋值（第3章-类和对象）：多个引用指向同一块内存，即 `StudentDemo a2 = a1;`。
- 引用与对象的区别：变量 `a1`、`a2` 存的是对象的地址（引用），不是对象本身；`new` 只出现一次，所以只创建了一个对象。

## 关键结论
- `a2 = a1` 是把 `a1` 存的地址复制给 `a2`，此后 `a1`、`a2` 指向堆内存中同一个 `StudentDemo` 对象；通过任一引用改成员变量，另一个引用看到的也是改后的值。
- 本例两次赋值的值相同（`name="xrs"`、`age=18`），所以输出看不出差别；要验证「同一对象」，应改成：先 `a1.age=18`，再 `a2.age=20`，然后打印 `a1.age`——若输出 20，就证明是同一对象。
- 与 Demo46 对照记忆：Demo46 是 `new` 两次＝两个对象、互不影响；Demo47 是 `new` 一次＋引用赋值＝一个对象、两个名字。

## 笔试易错点
- 高频考点：`StudentDemo a2 = a1;` 后 `a1` 和 `a2` 是不是同一个对象？是。问「创建了几个对象」按 `new` 的次数数，不是按引用变量个数数。
- 不要写成 `a2 = new StudentDemo()` 再说是同一对象——那样是第二个新对象。
- 对象作为引用类型，赋值传的是地址；基本类型（如 `int`）赋值传的是值本身，两者对比是选择题常考项。
