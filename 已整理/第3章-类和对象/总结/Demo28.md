# Demo28.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：一维数组的声明、默认初始化与元素赋值**

- `int arr[] = new int[3];`：声明一个长度为 3 的 int 型数组。`int arr[]` 与 `int[] arr` 写法等价，都是“arr 是一个 int 数组”。
- `System.out.println(arr);` 直接打印数组名，输出的不是元素，而是一串类似 `[I@哈希码` 的东西——数组名本质上是引用（地址），打印它只能看到类型标记 + 哈希码，看不到元素。
- `new int[3]` 创建后、赋值前，三个元素已有默认值：int 数组默认全是 0，所以一开始 `arr[0]`、`arr[1]`、`arr[2]` 都打印 0。
- 赋值后：`arr[0] = 200; arr[2] = 200;`，再打印时 arr[0]、arr[2] 是 200，而没被赋值的 arr[1] 仍是默认的 0。

**关键结论**

- 数组是引用类型：`new` 出来的数组先按类型给默认值（int 是 0，double 是 0.0，boolean 是 false，引用类型是 null），不会出现“未初始化”的随机值。
- 想看数组内容不能直接打印数组名，要逐个打印下标元素，或者用 `Arrays.toString(arr)`。
- 数组长度固定为 3，下标只能用 0、1、2，用到 arr[3] 就会越界报错。

**笔试易错点**

- ⚠️ 直接 `System.out.println(arr)` 的输出不是元素：填空题问“输出什么”时，数组名直接打印得到的是 `[I@...` 这类引用形式，千万别写成 0、0、0 或 200、0、200。
- ⚠️ 没赋值的元素不是“空”也不是报错：int 数组默认 0，本例 arr[1] 始终是 0——题目常拿这个设问，答“没有值”就错了。
- 下标从 0 开始：长度为 3 的数组最后一个元素是 arr[2]，不是 arr[3]；写 arr[3] 会抛 ArrayIndexOutOfBoundsException。
- `int arr[]` 与 `int[] arr` 都是合法写法，考试里两种都可能出现，别把 `int arr[]` 当成语法错误。
