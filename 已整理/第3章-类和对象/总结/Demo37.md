# Demo37 总结

## 练的知识点
- **带参数方法的定义与调用（形参与实参）**：定义 `isEvenNumber(int number)`，形参 `number` 接收调用时传来的值，方法内用 `number % 2 == 0` 判断偶数并打印。
- 两种实参调用方式都练到了：① 传常量值 `isEvenNumber(10)`；② 传变量 `int number = 10; isEvenNumber(number);`。两次调用都输出 `true`。

## 关键结论
- 带参方法是 Demo35 的进阶版：数不再写死在方法里，同一个方法可以反复用于不同的数，这才是方法复用的意义。
- 实参传给形参是“值传递”：传变量时是把变量的值（10）复制一份给形参，方法内改形参不影响 `main` 里的原变量（本例方法内没改，只是判断）。

## 笔试易错点
- 调用时实参类型必须与形参匹配：这里形参是 `int`，传 `10` 或 `int` 变量没问题，传小数或字符串会编译报错。
- `main` 的写法 `String args[]` 和常见的 `String[] args` 完全等价，括号位置不同而已，笔试见到别以为是错的。
- 形参名和 `main` 里的变量名都叫 `number` 只是巧合，两者是不同作用域的两个变量；方法内用的 `number` 是形参那一个，别混淆。
