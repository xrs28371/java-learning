# Demo34 总结

## 练的知识点
- 数组**求最大值**：先假设第一个元素最大 `int max = arr[0]`，再从下标 1 开始逐个比较，`if (arr[x] > max) max = arr[x];`，循环结束 `max` 即最大值。
- 本例数组 {12, 45, 98, 73, 60}，输出 max:98。

## 关键结论
- 求最值的标准套路：初始值取 `arr[0]`（不要取 0——全是负数时取 0 会错），比较从下标 1 开始。
- 这是编程大题原型之一：最值 / 查找 / 逆序 / 插入同一家族。

## 笔试易错点
- 循环从 `x = 1` 开始，因为 `arr[0]` 已作初值；从 0 开始也不错，但多比一次，要心里有数。
- 变量名 `x` 与下标混用没问题，但笔试默写时保持和自己模板一致，别临场改名写错。
