# Demo36 总结

## 练的知识点
- **无参方法的定义与调用**：在类中定义一个静态方法 `getmax()`，`main` 中调用它，方法体执行“打印两个数中较大数”的任务。
- 比较逻辑就是 `if (a > b)` 打印 `a`，否则打印 `b`；本例 `a = 10, b = 20`，运行输出 `20`。

## 关键结论
- 方法可以把一段固定任务封装起来：`main` 只需一句 `getmax();`，具体比较过程藏在方法体里。
- `if-else` 二选一结构：`a > b` 不成立时走 `else`，所以 `a == b` 时也会打印 `b`，结果同样正确。

## 笔试易错点
- 两个数是写死在方法内部的，换一对数就得改方法体——笔试编程题通常要求把数作为参数传进来（如 `getmax(int a, int b)`），只练这种写死版到考场上要会改写成带参版。
- 方法名按驼峰命名习惯应为 `getMax`，这里写成全小写 `getmax` 虽能编译，但笔试默写和平时都要按规范写，别养成小写连写的习惯。
- 方法体里的 `a`、`b` 是方法内部的局部变量，只在方法内有效；`main` 里不能直接用它们。
