# StudentDemo 总结

## 练的知识点
- 类的定义（第3章-类和对象）：用 `public class StudentDemo` 定义一个学生类，类名与文件名 StudentDemo.java 一致。
- 成员变量的定义：类体里直接写 `String name;` 和 `int age;`，分别表示学生的姓名和年龄。
- 成员方法的定义：`study()` 和 `doHomework()` 两个无参无返回值方法，方法体各用 `System.out.println` 打印一句提示，写法上一个是 `public void study(){...}` 紧凑式、一个是把 `{` 换行的松散式，两种格式都合法。
- （本次更新新增）成员方法里直接访问成员变量：新增的 `show()` 方法体只有 `System.out.println(name + age);`，方法内部不写 `s.`、直接用成员变量名，说明同一类的方法可以直接访问本类的成员变量。
- （本次更新新增）private 封装成员变量：`age` 由 `int age;` 改为 `private int age;`，表示年龄不再允许别的类直接读写，只能在本类内访问。
- （本次更新新增）get/set 方法对外提供受控访问：`setAge(int a)` 先校验 `a < 0 || a > 100`，不合法只打印 `Invalid Age` 且不赋值，合法才执行 `age = a`；`getAge()` 用 `return age;` 把私有年龄读出来。两者都用 public 修饰，注释里也写明了这套规则：private 修饰的成员变量如需被其他类使用，就配一对 public 的 get/set 方法。

## 关键结论
- 这份代码只负责「定义学生类」，本身没有 main 方法，不能直接运行；它要等 StudentDemo1 这样的测试类创建对象后才会被用到。
- 成员变量和方法都写在类体里、方法体外：name、age 是类的成员，不是某个方法的局部变量；study、doHomework 是类的方法，调用时必须通过对象（如 `s.study()`）。
- 当前两个方法的返回值都是 void、都没有参数，调用时只会打印固定的一句话，不接收、不返回任何数据。
- （本次更新）`show()` 同样是 void、无参，但它打印的不是固定文本，而是当前对象的 `name + age` 拼接结果——赋值前调它输出 `null0`，赋值后调它输出 `xrs10`，输出随对象状态变化；这正是「方法访问成员变量、结果跟对象走」的典型写法。
- （本次更新新增）封装的核心收益：年龄的合法性由 setAge 一处把关，外部再也写不进非法值——调用 `setAge(199)` 时 age 不会被改写，仍保持默认值 0；这正是注释里「直接赋值可能存在数据隐患」的对照：private + setAge 把校验收进了类内部，而不是靠调用者自觉。

## 笔试易错点
- 没有 main 方法就无法独立运行：考试若问「运行结果」，先确认有没有 main——StudentDemo 单独拿出来是跑不出输出的，必须配上带 main 的测试类。
- 成员变量与局部变量要分清：name、age 写在类体里才叫成员变量、才有默认值；若误写进方法体里就成了局部变量，未赋值使用会编译报错。
- 方法定义的完整形态：`public void study()` 中 public（访问修饰符）、void（无返回值）、方法名、空括号缺一不可；漏写 void 或括号都会编译报错。
- 类名与文件名必须一致：StudentDemo 类在 StudentDemo.java 文件中，一个文件中只能有一个 public 类，考试手写代码时先对齐文件名。
- 注意与同章旧文件区分：这里的 StudentDemo 与之前已有的 Student.java 是两个不同的类，不要混淆——StudentDemo 自带 name、age 和三个方法，是目前可直接拿来创建对象的完整学生类。
- （本次更新易错）`show()` 里 `name + age` 同样是字符串拼接：因为 name 是 String，输出是 `null0` / `xrs10` 这样连在一起的字符串，不要写成带空格的 `null 0`，也不要当成数值相加；且方法内直接写 `name` 指的就是当前对象的成员变量，不要画蛇添足写成 `s.name`（方法里没有 s 这个变量）。
- （本次更新新增易错）private 的边界：private 修饰的成员「只在本类中才能访问」——别的类里写 `s.age` 会编译报错，必须走 `s.setAge(...)` / `s.getAge()`；但注意 `name` 没有加 private，仍可直接 `s.name` 读写，不要把两个成员的访问权限混为一谈。
- （本次更新新增易错）setAge 的校验边界：条件是 `a < 0 || a > 100`，所以 0 和 100 都是合法值（能赋值），101 才算非法；且非法时方法只是打印 `Invalid Age`、不赋值、不报错——程序会继续往下跑，age 保持原值，不要把「打印 Invalid Age」当成程序异常终止。
- （本次更新新增易错）get/set 的命名与签名：读方法叫 `getAge()`（无参、有返回值 int）、写方法叫 `setAge(int a)`（有参、无返回值 void），考试手写时方法名大小写和括号不能错，`getage`、`setage` 都会找不到方法。
