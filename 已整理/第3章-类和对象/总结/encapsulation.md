# encapsulation.java 总结

## 这份代码在练什么
纯概念笔记类代码，主练**封装（encapsulation）**：面向对象三大特征之一（封装、继承、多态），文件里没有可运行的字段和方法，只有封装原则的文字总结。

## 关键内容
- 封装原则：将某些信息隐藏在类的内部，不允许外部程序直接访问。
- 实现手段：字段用 `private` 修饰，对外通过 `get` / `set` 方法访问。
- 两个好处：提高安全性（外部不能乱改内部数据）、提高复用性。

## 笔试易错点
1. 封装不等于只写 private：private 字段必须配 get/set，否则外部完全无法读写，等于把数据封死——笔试标准答案形态是「private 字段 + get + set」三件套。
2. 本文件只是概念提纲，真正练封装要看同章节的 Student.java / StudentDemo.java：private 字段 + this + 带校验的 set 才是完整写法，别只背概念不写代码。
3. 注意类名规范：Java 类名按惯例首字母大写（应为 Encapsulation），本文件类名 `encapsulation` 全小写，笔试写代码时按规范写大写开头；另注意文件名与 public 类名必须一致。
