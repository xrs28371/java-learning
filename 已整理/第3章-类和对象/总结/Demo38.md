# Demo38 总结

## 练的知识点
- **带两个参数的 void 方法的定义与调用**：定义 `getMax(int a, int b)`，用 `if-else` 比较两个数，在方法内直接 `System.out.println` 打印较大数，没有返回值。
- 两种实参调用方式都练到了：① 传常量 `getMax(10, 20)`；② 先定义变量 `int a = 10; int b = 20;` 再传变量 `getMax(a, b)`。两次调用都输出 `20`。

## 关键结论
- 这是 Demo37（单参方法）的进阶：参数从一个变两个，调用时就要按顺序给两个值，形参按位置一一对应——第一个实参给 `a`，第二个给 `b`。
- void 方法的特点是“只做事、不给回结果”：较大数直接在方法里打印出来，`main` 里拿不到这个数，后续想再用它（比如再比较、再计算）就没办法，这是 Demo40 改用返回值的原因。

## 笔试易错点
- 调用时实参个数和类型必须与形参完全匹配：代码里被注释掉的两行就是反例——`getMax(30)` 少一个参数、`getMax(10.0, 20.0)` 传了 double，都会编译报错。
- `a == b` 时走 `else` 分支打印 `b`，结果和打印 `a` 一样（两数相等），不算错，别误以为 `else` 只对应 `a < b` 就漏了相等的情况。
- 形参 `a`、`b` 和 `main` 里的变量 `a`、`b` 只是同名、不同作用域：方法内用的是形参，传变量时传的是值（10、20）的副本。
