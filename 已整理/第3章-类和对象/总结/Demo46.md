# Demo46 总结

## 练的知识点
- 类与对象的使用（第3章-类和对象）：用 `new` 创建多个对象，分别给成员变量赋值、调用成员方法。
- 多个对象相互独立：`s1` 和 `s2` 是两个不同的 `StudentDemo` 对象，各自的 `name`、`age` 互不影响。

## 关键结论
- 创建对象的标准写法：`类名 对象名 = new 类名();`，然后用 `对象名.成员变量` 赋值、用 `对象名.成员方法()` 调用方法。
- 本例中两个对象都被赋了相同的值（`name="xrs"`、`age=30`），输出也相同，但它们是两块独立的内存——改 `s1` 不会影响 `s2`，这是与 Demo47（同一对象两个引用）的关键区别。
- 调用方法不用加参数：`study()`、`doHomework()` 都是无参成员方法，直接 `对象名.方法名()` 即可。

## 笔试易错点
- 选择/填空常考「创建几个对象」：`new` 出现几次就创建了几个对象，本例 `new StudentDemo()` 出现两次，就是两个对象。
- 不要把「两个对象值相同」理解成「同一个对象」：值相同只是巧合赋值，内存地址不同。
- `System.out.println("Name:"+s1.name)` 是字符串拼接，`+` 两边类型不同时先把非字符串转成字符串再拼接。
