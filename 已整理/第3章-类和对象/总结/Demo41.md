# Demo41 总结

## 练的知识点
- **方法重载（overload）**：同一类里三个同名方法 `sum`：`sum(int, int)`、`sum(double, double)`、`sum(int, int, int)`，注释里写明了重载三要素——同一个类、相同方法名、参数不同（类型不同或数量不同）。
- **重载方法的调用与返回值接住**：`main` 里依次调用 `sum(10, 20)` 得 `30`、`sum(10.0, 20.0)` 得 `30.0`、`sum(10, 20, 30)` 得 `60`，都用变量接住再打印。

## 关键结论
- 重载只看参数列表（个数、类型、顺序），与返回值类型无关：不能只靠返回值不同来区分两个方法，那样编译报错。
- 编译器按实参的类型和个数匹配最合适的方法：传两个 `int` 走 `sum(int, int)`，传两个 `double` 走 `sum(double, double)`，传三个 `int` 走三参版——方法名相同，实际执行的是不同方法体。
- 注释里的两条规则也要记牢：方法不能嵌套定义（不能在 `main` 里面再定义一个方法）；`void` 表示没有返回值。

## 笔试易错点
- 注释有错别字：“多个方法再同一个类中”应为“在同一个类中”，笔试写概念表述时别抄错。
- 调用时参数个数、类型、顺序必须与某个重载版本对上：如 `sum(10, 20.0)`（一个 int 一个 double）在这里没有对应版本，会编译报错。
- `sum(10.0, 20.0)` 输出的是 `30.0` 而不是 `30`：double 版返回 double，打印带小数点；判运行结果题时注意类型决定输出格式。
- 注意 `main` 里 `sum` 是静态方法直接调用的：因为 `sum` 都声明为 `static`，才能在静态的 `main` 里直接用方法名调用；非静态方法则不行（见 Demo42 的对比）。
