# PhoneDemo 总结

## 练的知识点
- 对象的创建（第3章-类和对象）：在 main 方法里用 `Phone p = new Phone();` 创建 Phone 类的对象。
- 类与测试类的分工：Phone.java 只负责定义类（属性＋方法），PhoneDemo.java 是带 main 方法的测试/演示类，负责创建对象并使用它，是考试编程题里常见的「一类一文件＋一个 Demo」的写法。

## 关键结论
- `new Phone()` 的含义：new 在堆内存中开辟空间、创建 Phone 对象，`Phone p` 是引用变量，p 中存的是对象的地址，之后要通过 `p.` 访问属性和方法。
- 目前代码只做到「创建对象」这一步，还没有调用 `p.call()` / `p.sendMessage()`，所以运行起来没有任何输出；补上两句调用后才会打印「打电话」「发短信」。

## 笔试易错点
- 只创建对象、不调用方法，是初学最常见的「写了却没效果」：笔试编程题要求「创建对象并调用方法」时，漏掉调用句会被扣分，创建和调用是两步，缺一不可。
- `Phone p = new Phone();` 三段缺一不可：类型 `Phone`、变量名 `p`、`new Phone()`；写成 `Phone p = Phone();`（漏 new）或 `new Phone;`（漏括号）都会编译报错。
- 类名与文件名必须一致：PhoneDemo 类在 PhoneDemo.java 文件中，Phone 类在 Phone.java 文件中；一个文件中只能有一个 public 类，且类名须与文件名相同，考试手写代码时先对齐文件名。
- 编译运行注意：PhoneDemo 依赖 Phone 类，两个文件须放在同一目录（同一包）下一起编译，只拷一个文件会报「找不到符号 Phone」。
