# PhoneDemo 总结

## 练的知识点
- 对象的创建与使用（第3章-类和对象）：在 main 方法里用 `Phone p = new Phone();` 创建 Phone 类的对象，再通过 `p.` 访问成员变量和成员方法。
- 成员变量的读写：先打印默认值（`p.brand`、`p.price`），再赋值（`p.brand = "小米"`、`p.price = 100`）后重新打印，验证赋值生效。
- 成员方法的调用：`p.call()`、`p.sendMessage()`，对象创建后必须显式调用方法才会执行方法体。

## 关键结论
- `new Phone()` 的含义：new 在堆内存中开辟空间、创建 Phone 对象，`Phone p` 是引用变量，p 中存的是对象的地址，之后一律通过 `p.` 访问属性和方法。
- 未赋值的成员变量有默认值：引用类型 `brand` 默认 null，数值类型 `price` 默认 0，所以第一次打印输出 null 和 0；赋值后第二次打印输出「小米」和 100。
- 运行顺序即代码顺序：打印默认值 → 赋值 → 打印新值 → 调用 call → 调用 sendMessage，最终输出依次为 null、0、小米、100，以及 call / sendMessage 方法体打印的内容。

## 笔试易错点
- 成员变量默认值是高频考点：引用类型默认 null、int 默认 0、boolean 默认 false；把「未赋值就打印」写成报错是错的，能编译能运行，只是输出默认值。
- 对象使用三步缺一不可：创建（`new Phone()`）→ 赋值/调用缺一不可；只创建不调用方法，方法体永远不会执行。
- `Phone p = new Phone();` 三段缺一不可：类型 `Phone`、变量名 `p`、`new Phone()`；写成 `Phone p = Phone();`（漏 new）或 `new Phone;`（漏括号）都会编译报错。
- 类名与文件名必须一致：PhoneDemo 类在 PhoneDemo.java 文件中，Phone 类在 Phone.java 文件中；一个文件中只能有一个 public 类，且类名须与文件名相同，考试手写代码时先对齐文件名。
- 编译运行注意：PhoneDemo 依赖 Phone 类，两个文件须放在同一目录（同一包）下一起编译，只拷一个文件会报「找不到符号 Phone」。
- 格式细节不影响编译：当前版本里 `Phone p =new Phone();` 的 `=` 后少了一个空格，这只是书写格式问题，不影响编译和运行，笔试誊写时按规范空格写即可。
