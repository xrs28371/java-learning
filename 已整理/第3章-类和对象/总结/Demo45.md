# Demo45 总结

## 练的知识点
- 类与对象的基本概念（第3章-类和对象）：类是对象的数据类型，是具有相同属性和行为的一组对象的集合；对象是看得见摸得着的真实存在实体。
- 类与对象的关系：类是对一类有共同属性和行为的抽象，对象是类的具体实例。
- 类的组成：属性用成员变量体现，行为用成员方法体现；类是 Java 程序的基本组成单位。

## 关键结论
- 属性 = 对象具有的各种特征，每个对象的每个属性都有特定的值；行为 = 对象能执行的操作。
- 记忆口诀：类是抽象的模板，对象是具体的实体；写代码时先定义类（属性＋方法），再创建对象使用。

## 笔试易错点
- 概念辨析常考：不要把「类」和「对象」说反——类是抽象、一类事物的统称，对象才是具体存在的一个个体。
- 本文件目前只有概念注释、没有可运行的类定义与对象创建代码，复习时以概念记忆为主；想练手感要看同章的 Phone.java / PhoneDemo.java，那一对才是真正定义类并创建对象的代码。
