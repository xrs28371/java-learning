# Demo27027 总结

> 本文件即原 Demo27 改名而来：猜数字游戏（今日自测的闭卷默写题）。

## 练的知识点
- `Random` 生成随机数：`rand.nextInt(100) + 1` 得到 1~100。
- `Scanner` 读键盘输入：`sc.nextInt()`。
- `while(true)` 无限循环 + 猜中时 `break` 跳出。
- `if / else if / else` 三分支比较：大了、小了、猜中。

## 关键结论
- 程序骨架完整：生成随机数 → 循环读输入 → 比较给提示 → 猜中 break 结束。
- 类名已随文件名同步改为 `Demo27027`，可正常编译运行。

## 笔试易错点
- `nextInt(100)` 本身是 0~99，必须 +1 才是 1~100。
- 猜中分支里别漏 `break`，否则死循环。
- `Random`、`Scanner` 都要 import（`java.util.Random`、`java.util.Scanner`）。
