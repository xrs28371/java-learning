# Demo43 总结

## 练的知识点
- **基本类型参数的传递**：`main` 里 `int num = 100`，调用 `change(num)`，`change` 方法里把形参 `num` 改成 200，再回到 `main` 打印 `num`，验证实参有没有被改动。
- **方法定义与调用**：`change` 是静态方法，在静态的 `main` 里直接用方法名调用；方法内对形参赋值，方法外不受影响。

## 关键结论
- Java 的参数传递永远是**按值传递**：基本类型传的是值的副本，方法里改的是副本，实参本身纹丝不动。
- 所以运行输出是两行 `100`、`100`：调用前打印 100，`change(num)` 内部把副本改成 200 但随方法结束就丢弃了，调用后 `main` 里的 `num` 仍是 100。

## 笔试易错点
- 形参和实参同名（都叫 `num`）不代表是同一个变量：方法里的 `num` 是独立的局部副本，改它不影响 `main` 里的 `num`；同名是这道题最常见的迷惑点。
- 不要把输出写成 `100`、`200`：第二行仍是 100；只有把 `change` 的返回值接住并重新赋值给 `num`（如 `num = change(num)` 且方法返回 int）才能真正改动。
- 本题是 Demo44 的对照组：基本类型改不动、引用类型改得动，两题成对出现时要分清传递的是“值”还是“引用（地址）的副本”。
