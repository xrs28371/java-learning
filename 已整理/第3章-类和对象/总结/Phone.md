# Phone 总结

## 练的知识点
- 类的定义与组成（第3章-类和对象）：一个类由成员变量（属性）和成员方法（行为）组成。
- 成员变量：`String brand`（品牌，字符串类型）、`int price`（价格，整型），写在类里、方法外，不用 static，不初始化时有默认值（String 默认 null，int 默认 0）。
- 成员方法：`call()` 输出「打电话」，`sendMessage()` 输出「发短信」，都是无参无返回值（void）方法，模拟手机的两个行为。

## 关键结论
- 这是「定义类」的标准模板：属性对应名词（品牌、价格），方法对应动词（打电话、发短信）；先有这个类，PhoneDemo.java 才能用 `new Phone()` 创建对象。
- 类本身不产生输出：只有创建对象并调用方法时，`call()` / `sendMessage()` 里的打印语句才会执行。

## 笔试易错点
- 成员变量和局部变量别混：brand、price 写在类中方法外，是成员变量，整个对象都可用；写在方法里才是局部变量，只在方法内有效。
- 成员变量不写访问修饰符时默认是包级私有（package-private），不是 public 也不是 private；笔试问「默认访问权限」时答包访问权限，别顺手写成 public。
- 方法签名注意：`public void call()` 中 void 表示无返回值，调用时不能写成 `String s = p.call();` 接收结果；无参方法调用必须带空括号 `p.call()`，漏括号会编译报错。
- 本文件只有类定义、没有 main 方法，不能直接运行；要运行须配合 PhoneDemo.java 一起编译运行。
