# Demo35 总结

## 练的知识点
- **方法的定义与调用**：方法类似 C 语言中的函数，先定义、后使用，且必须手动调用才会执行。
- 本例在类中定义了一个静态方法 `isEvenNumber()`，内部定义变量 `number = 10`，用 `number % 2 == 0` 判断是否为偶数并打印结果；`main` 中调用了它，运行输出 `true`。

## 关键结论
- 方法定义了不等于执行了：只有 `main` 里的 `isEvenNumber();` 这一句调用，才让方法体真正跑起来。
- 判断偶数的核心写法是 `number % 2 == 0`，余数为 0 即偶数，本例 10 是偶数故输出 `true`。

## 笔试易错点
- 本例的数是写死在方法内部的（`int number = 10;`），换个数就得改方法体——可复用性差；进阶写法是像 Demo37 那样把数作为参数传进来。
- 方法名 `isEvenNumber`（是不是偶数）按命名习惯应返回布尔值，但这里声明为 `void`、靠打印输出结果；笔试默写时要让方法名、返回值、输出三者一致，别把“打印版”和“返回版”混写。
- 静态方法用 `public static` 修饰，才能在 `main`（同样是静态方法）里直接调用；漏写 `static` 会导致 `main` 里调不动它。
