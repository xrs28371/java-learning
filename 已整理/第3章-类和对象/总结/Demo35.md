# Demo35 总结

## 练的知识点
- **方法的定义与调用**：方法类似 C 语言中的函数，先定义、后使用，且必须手动调用才会执行。
- 本例在类中定义了一个静态方法 `isEvenNumber()`，内部用 `number % 2 == 0` 判断一个数是否为偶数。

## 关键结论
- 方法定义了不等于执行了：本例 `main` 方法里没有任何调用语句，所以程序运行时什么都不输出，`isEvenNumber()` 从头到尾没有被执行过。
- 判断偶数的核心写法是 `number % 2 == 0`，余数为 0 即偶数。

## 笔试易错点
- **本例是半成品，两个坑要直接点出**：① `isEvenNumber()` 在 `main` 中没有被调用，等于白写；② 即使调用了，`if` 分支里也是空的，既没打印结果也没返回值，调用后依然看不到任何效果——完整写法应在分支里 `System.out.println` 输出结果，或把方法改成返回 `boolean`。
- 方法名 `isEvenNumber`（是不是偶数）按命名习惯应返回布尔值，但这里声明为 `void` 且无输出，名不副实；笔试默写时要让方法名、返回值、输出三者一致，别照抄这种半成品。
- 静态方法用 `public static` 修饰，才能在 `main`（同样是静态方法）里直接调用；漏写 `static` 会导致 `main` 里调不动它。
