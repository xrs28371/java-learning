# Demo48 总结

## 练的知识点
- 成员变量与局部变量的区别（第3章-类和对象）：定义位置不同、内存位置不同。

## 关键结论
- 定义位置：成员变量在类中、方法外；局部变量在方法内或方法声明的参数位置上。
- 内存位置：成员变量随对象存在堆内存中；局部变量随方法调用存在栈内存中，方法结束即消失。
- 派生区别（笔试常连带考）：成员变量有默认值（如 `int` 默认 0、`String` 默认 `null`），局部变量没有默认值，使用前必须先赋值，否则编译报错。

## 笔试易错点
- 本文件目前只有注释、没有可运行的示例代码，复习时以概念辨析为主；真正区分两者要结合 Demo46/Demo47 里的 `StudentDemo`（`name`、`age` 是成员变量）与 `main` 方法里的 `s1`、`s2`（局部变量）对照看。
- 注释只写了位置区别，没写默认值和生命周期区别，答题时要补上：成员变量随对象生死、局部变量随方法调用生死。
- 不要把「方法声明上的参数」漏掉——形参也是局部变量的一种。
