# Demo21.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：for 循环——刚起头的空骨架，尚未写入任何循环代码**

- 文件目前只有 `public static void main(String[] args)` 骨架和一行注释 `//for循环`，方法体内没有任何语句、没有任何 for 语句。
- 这是一个刚新建、还没开始写的练习文件，注释标明下一步要练 for 循环，但循环本身还没写出来。

**关键结论**

- 有 main 方法的空程序可以编译、可以运行，只是运行后没有任何输出；与之前 Demo19 旧版“连 main 都没有、无法运行”不同，本文件已具备运行条件。
- 注释不影响程序：`//for循环` 只是给自己留的提示，编译器会直接忽略，真正要练的 for 循环语法（初始化、条件、步进三部分）还需后续补上。

**笔试易错点**

- 不要把“注释里写了 for”当成“已经练了 for”：考试问 for 循环写法时，空文件给不出任何有效代码，复习时要以实际写出的循环为准。
- 动手前先确认本文件确实是空的，避免和 Demo19、Demo20 这类已写好的 switch 练习混淆；写 for 循环时先搭 `for (初始化; 条件; 步进)` 骨架，再填循环体，防止把条件写反造成死循环。
