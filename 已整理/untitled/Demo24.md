# Demo24.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：do-while 循环——先执行一次、再判断条件**

- `int j = 1;`，`do { System.out.println(j); j++; } while (j <= 5);`，打印 1、2、3、4、5。
- 注释点出与 for 的区别：for 循环里声明的自增变量只归 for 所有、循环结束就无法访问；而 while / do-while 的变量是在循环外声明的，循环结束后仍可访问。

**关键结论**

- do-while 的执行顺序是“先执行循环体、再判断条件”，所以循环体至少执行一次——这是它与 while / for 最本质的区别。
- 本例中 j 从 1 打印到 5：每次打印后 j++，当 j 变成 6 时条件 `j <= 5` 不成立，循环结束。

**笔试易错点**

- ⚠️ “至少执行一次”是 do-while 的必考点：即使初始条件就不成立（如 j 初始就是 6），do-while 也会先打印一次再退出，而 while 则一次都不执行——题目问“输出什么”时先看是 do-while 还是 while。
- do-while 末尾的 `while (条件);` 那个分号不能漏：漏写分号编译报错；多写成 `while (j <= 5)` 后再跟分号以外的语句也容易读错结构。
- 循环变量的自增不能漏：`j++` 漏写则 j 恒为 1、条件恒成立，变成死循环。
- 作用域：for 括号里声明的 `int i` 只在 for 内有效，循环外再用 i 会编译报错；do-while / while 的变量在循环外声明，循环结束后仍能用——反过来也意味着它不会随循环自动销毁，别在后面误用残值。
