# Demo24.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：一个空类骨架，什么都没写**

- 文件里只有一个 `public class Demo24 {}`，没有 main 方法、没有字段、没有方法，编译能通过，但运行起来什么都不做。

**关键结论**

- 空类本身是合法的 Java 代码：类可以没有任何成员，编译不报错。
- 但没有 main 方法的类不能作为程序入口直接运行——这是“新建文件后还没开始写”的占位状态，不是完整程序。

**笔试易错点**

- ⚠️ 空类≠程序：考试或上机要求“写一个程序”时，光有类名没有 main 方法等于没交卷；新建文件后先把 `public static void main(String[] args)` 的骨架搭好再往里填。
- 类名与文件名必须一致：`Demo24` 类必须放在 `Demo24.java` 里，改名只改一处就会编译报错。
