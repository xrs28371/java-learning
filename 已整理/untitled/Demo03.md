# Demo03.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：变量、基本数据类型、标识符规则、类型转换**

- 变量定义与修改：`int a = 10;` 输出后改成 20 再输出。
- 基本类型逐个定义并输出：`byte`、`short`、`int`、`char`（`'a'`）、`boolean`（`true`）、`long`（字面量后加 `L`）、`double`（`13.14`）。注释强调 Java 是强类型语言、`float` 字面量要加 `F`。
- 类型转换：
  - 自动转换（小范围 → 大范围）：`int` 赋给 `double` 输出 `20.0`；`byte t = 10` → `short` → `long` 链式赋值。
  - 强制转换：`(int) 88.88` 结果为 `88`，小数部分被截断，注释写明会丢失数据。

**易错点（本文件注释里有一处写错了）：**

- 注释把标识符组成写成“数字、字符、下划线（-）和美元符号（$）”——标识符里是**下划线 `_`**，不是短横线 `-`；短横线在代码里是减号，不能出现在标识符中。
- 后半段 `byte t`、`short aa` 已经先用过又被 IDEA 标为冗余变量（定义后只用一次），属黄色警告，不是错误。
