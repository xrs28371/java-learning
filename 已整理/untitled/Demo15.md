# Demo15.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：流程控制语句概述——顺序结构演示**

- 代码先用注释列出流程控制的三大结构：顺序结构、分支结构、循环结构，但本例只实现了第一种，分支和循环尚未展开（只是提纲）。
- 顺序结构演示：依次打印“开始”→ 三次“语句A” →“结束”，输出顺序与代码书写顺序完全一致，没有任何判断或跳转。
- 关键结论：顺序结构是 Java 的默认执行方式——不写分支/循环时，程序就是从上到下逐行执行。

**笔试易错点**

- 顺序结构没有条件：不要在只有 println 的代码里找 if/循环的执行路径，输出就是代码顺序。
- 三次打印的都是同一个字符串“语句A”，不是三个不同语句，默写或改错时注意别把它当成 A/B/C 三个变量。
