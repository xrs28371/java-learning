# Demo18.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：单分支 if 语句——成绩低于阈值时输出一句话**

- 用 Scanner 读入一个整数 score，只有一个 if 分支：`if (score <= 80)` 成立时打印“胖揍一顿”，不成立时什么都不输出、程序直接结束。
- 这是 if 语句最简单的格式 1：只有一个条件、一个分支，没有 else 兜底。

**关键结论**

- 单分支 if 只管“成立时做什么”，条件不成立时程序静默跳过，不会报错、也不会自动输出任何提示；需要“否则”逻辑时必须自己补 else。
- 条件 `score <= 80` 是“小于等于”，score 恰好等于 80 时分支也会执行；写成 `< 80` 则 80 分不触发，边界值是笔试常考点。

**笔试易错点（直接点出）**

- **代码本身有编译错误：第 8 行 `System.out.println("胖揍一顿")` 末尾漏了分号 `;`**，Java 每条语句必须以分号结尾，缺分号编译直接报错，程序根本跑不起来——这是本文件目前最要紧的问题，补上分号才能运行。
- if 的条件要用 `<=` 这样的关系运算符，写成 `=` 是赋值，编译报错；条件后的括号不能省。
- 本例没有输入提示语（Demo17 有 `请输入一个星期数`，这里直接 `nextInt()`），运行时光标只会干等，容易让人误以为程序卡死；考试写代码时建议先打印提示再读数。
- score 未做范围校验：输入负数或大于 100 的数也会照常比较，`<= 80` 成立就打印，不会触发任何“输入错误”处理。
