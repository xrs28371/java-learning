# Demo23.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：while 循环 + 指数增长——一张纸折多少次能达到珠穆朗玛峰的高度**

- 纸厚 0.1 毫米，珠峰高 8844430 毫米（8844.43 米），只要 `paperThickness < everestHeight` 就继续折，每折一次厚度翻倍（`paperThickness *= 2`），同时 `count++`，最后打印折叠次数。

**关键结论**

- 这是“不知道要循环多少次”的典型场景，只能用 while，不能用次数固定的 for：循环条件是“还没达到目标”，而不是“数到第几次”。
- 指数增长非常快：0.1 毫米翻倍 27 次就超过 8844 米，所以答案是 27 次——直觉上“几万次”就错了，翻倍增长是指数级，不是线性。
- 算式验证：0.1 × 2^26 ≈ 671 万毫米，还不够；0.1 × 2^27 ≈ 1342 万毫米，超过 8844430 毫米，所以循环在第 27 次后停下。

**笔试易错点**

- ⚠️ 循环条件写反会直接出事：写成 `while (paperThickness > everestHeight)` 一开始就不成立，一次都不折，count 为 0；写成死循环条件（如漏写 `paperThickness *= 2`）则永远达不到目标、停不下来。
- 单位要统一：珠峰高度题目给的是毫米 8844430，如果写成 8844.43（米）去和 0.1 毫米比较，答案会错成 17 次——比较前先把单位换算成一致的。
- `paperThickness` 必须用 double：厚度翻倍后很快超过 int 能表示的范围不说，0.1 本身就是小数，用 int 存会直接变成 0，循环永远结束不了。
- `count++` 要放在循环体内、翻倍语句之后：放在循环外只会得到 1；漏写则 count 恒为 0。
