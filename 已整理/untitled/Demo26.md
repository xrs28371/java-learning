# Demo26.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：循环嵌套——用双层 for 循环输出一天的小时和分钟**

- 外层循环控制小时：`for (int hour = 0; hour <= 24; hour++)`，内层循环控制分钟：`for (int min = 0; min < 60; min++)`，内层每跑完一轮（0–59 分），外层小时才 +1。
- 输出格式是 `hour + "时" + min + "分"`，即 `0时0分、0时1分……0时59分、1时0分……` 这样逐行打印。

**关键结论**

- 循环嵌套的执行规律：外层跑 1 次，内层跑完整整一轮；总行数 = 外层次数 × 内层次数。本例外层 25 次 × 内层 60 次 = 1500 行。
- 这是嵌套循环最典型的“外层管组数、内层管组内个数”结构：小时是组，分钟是组内的项。

**笔试易错点**

- ⚠️ **外层边界写错了：`hour <= 24` 会多出一小时。** 一天是 0–23 时共 24 个小时，正确条件应为 `hour < 24`；现在这样会多打印 `24时0分` 到 `24时59分` 共 60 行——24 时在一天里根本不存在，考试写运行结果时这 60 行就是错的。
- `<=` 与 `<` 差一次是循环题最高频的坑：分钟用 `< 60`（0–59）是对的，小时却用了 `<= 24`（0–24），两层边界写法不一致，读题时要逐层数清楚起止值。
- 嵌套循环内外层变量必须不同：这里外层 `hour`、内层 `min` 各司其职；若两层共用一个变量，内层会把外层的计数改乱，结果全错。
- 类名与文件名必须一致：`Demo26` 类必须放在 `Demo26.java` 里，改名只改一处就会编译报错。
