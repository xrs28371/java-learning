# Demo26.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：一个只有注释的空骨架——“循环嵌套”还没开始写**

- 文件里只有一个 `public class Demo26` 加 main 方法骨架，方法体内除了一行注释 `//循环嵌套` 外没有任何代码，编译能通过，但运行起来什么都不输出。

**关键结论**

- 这是“新建文件、先占位、还没填内容”的状态，不是完整程序：注释写明了下一练的主题是循环嵌套，但嵌套代码本身尚未写出。
- 循环嵌套的一般形态是“外层循环控制行（或组数）、内层循环控制列（或每组内的个数）”，如打印矩形、九九乘法表都是这个结构——本文件目前还没有任何一层。

**笔试易错点**

- ⚠️ 空骨架≠已掌握：考试或上机要求“写循环嵌套程序”时，光有注释没有代码等于没交卷；新建文件后先把内外两层循环的骨架搭好再往里填。
- 嵌套循环最容易错的是内外层变量混用：内层和外层必须用不同变量（如 i 和 j），共用一个变量会互相干扰、结果全乱。
- 类名与文件名必须一致：`Demo26` 类必须放在 `Demo26.java` 里，改名只改一处就会编译报错。
