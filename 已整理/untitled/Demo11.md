**主题：三元运算符案例——两只老虎体重是否相同**

- 定义两只老虎的体重 `weight1 = 180`、`weight2 = 200`。
- 用三元运算符判断：`boolean b = weight1 == weight2 ? true : false;`，输出 `b:false`（体重不同）。
- 小提示：`x ? true : false` 其实就等于 x 本身，这里直接写 `boolean b = weight1 == weight2;` 结果一样；课程案例这么写是为练三元格式，笔试里两种写法都对。
