# Demo17.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：if-else if-else 多分支——数字转星期**

- 注释已点明主题：if 语句格式 3，即 `if – else if – else` 多分支结构。
- 先用 Scanner 读入一个整数 week，再按 1~7 逐个比对：1 打印“星期一”，2 打印“星期二”，……，6 打印“星期六”，其余情况一律走 else 打印“星期日”。
- 多分支是“自上而下、命中即停”：一旦某个条件成立就执行对应分支并跳出整个链，后面的 else if 不再判断。

**笔试易错点**

- else 没有自己的条件：它承接的是前面所有条件都不成立的情况。本例 else 打印“星期日”并不等于条件 `week == 7`——输入 8、0、负数等非法值也会落入 else 被当成“星期日”，这是本题最大的逻辑漏洞；严谨写法应在 else 前加 `else if (week == 7)`，再用 else 处理“输入错误”。
- else if 的条件要用 `==` 比较，写成 `=` 会赋值且对 int 类型编译报错。
- 链式判断只走一个分支：输入 1 时只打印“星期一”，不会顺带打印后面的星期；若把 else if 全改成独立 if，逻辑就变了（本题因条件互斥结果碰巧相同，但语义和效率不同，考试要区分）。
- 输入范围提示是“1~7”，但代码没有对范围外输入做校验，笔试若问“输入 8 输出什么”，答案是“星期日”，不是报错。
