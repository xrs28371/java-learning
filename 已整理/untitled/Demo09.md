# Demo09.java 内容总结

> 文件名是随手取的，以下按代码实际内容总结。

**主题：短路逻辑运算符（&&、||）与 &、| 的区别**

- 先用 `i = 10`、`j = 20`、`k = 30` 把 && 和 || 的四种真假组合各验一遍，结论与 Demo08 相同：&& 都是 true 才为 true，|| 有 true 就为 true。
- 本文件真正的重点在最后（考点）：用自增做对照实验——`(i++ > 100) & (j++ > 100)` 中左边已是 false，但 `&` 右边照样执行，j 被自增到 21；而 `(i++ > 100) && (j++ > 100)` 中左边 false 后 `&&` 直接短路，右边不执行，j 停在 21。最终输出 i = 12、j = 21。
- 这正是自测单 (b) 题要的区别：**&& 左边为 false 右边不执行，|| 左边为 true 右边不执行**；单符号 &、| 则两边都算。
